# SimpleGame

横版双线推兵策略游戏原型。设计文档在 [Docs/README.md](Docs/README.md)。

## 当前状态

M3 镜头、小地图与三关：

- 世界宽 1600，640x360 视口；镜头跟随当前路前线
- 小地图显示两路基地、单位、推进线、镜头范围；可点击切路/跳转
- 推进线默认基地门口；新兵前往推进线驻守，不再自动冲到底
- 鼠标框选/点选己方单位，右键移动，`H` 驻守，`R` 返回推进线
- 第 1-3 关固定波次；`N` 切下一关
- 金币/人口/建筑/6 兵种/精英/波次结算沿用 M2
- 占位矩形渲染；画布 640x360，窗口 1280x720

> M3 仍为系统测试：三关都解锁全部 6 兵种与两种建筑；GDD 的逐关解锁在 M4 接入。教学降维 M5。

```bash
"D:/Godot_v4.7/Godot_v4.7-stable_win64.exe" --path .
```

## 操作

| 输入 | 行为 |
|---|---|
| 左键点击/拖框 | 选择己方单位；`Shift` 加选 |
| 右键地面 | 选中单位移动到该位置 |
| `Shift + 右键` | 设置当前路的推进线（新兵会前往并驻守） |
| `H` | 选中单位原地驻守 |
| `R` | 选中单位返回推进线 |
| `Ctrl + R` | 重开当前关 |
| `1-6` | 在当前路出兵（剑盾/长矛/弓/法/骑/投石） |
| `Alt + 1-6` | 在另一条路出兵 |
| `Q` / `E` | 切换当前路并跟随镜头 |
| 点击小地图 | 切到该路并跳到点击位置 |
| `F` | 开关镜头跟随 |
| `A` / `D` | 手动平移镜头（会关闭跟随） |
| `Home` | 镜头回基地 |
| `B` 或点击 BUILD | 打开/关闭建筑面板 |
| 点击建筑行 | 建造/升级对应槽位 |
| `N` | 下一关 |
| `Space` | 暂停/继续 |
| `Esc` | 退出 |

**关键**：新兵默认在基地门口驻守。先用 `Shift + 右键` 把推进线压到前面，否则敌人远程单位会在你射程外停住。

## 测试

```bash

```

覆盖：出兵/推进、推进线/移动/驻守/返回、跨路不交战、伤害/被动/溅射、基地胜负、金币/人口/冷却、农场/兵营、击杀奖励、固定波次、三关数据、HUD 点击/小地图、镜头跟随/边界、确定性。

```bash
"D:/Godot_v4.7/Godot_v4.7-stable_win64.exe" --headless --path . --script tests/autoplay.gd
```

当前结果：三关均可通关；第 3 关基地约剩 3/20，作为难度上限。
