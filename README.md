# SimpleGame

横版双线推兵策略游戏原型。设计文档在 [Docs/README.md](Docs/README.md)。

## 当前状态

M1 自动战斗原型：

- 2 条平行路，双方基地血量 10（M1 调试值；正式关卡 20）
- 单位从基地门口生成，自动推进、索敌、攻击
- 剑盾兵 / 弓箭手可出战（数据表已含 6 兵种，M2 接入）
- 软克制、破甲、盾墙、冲锋、溅射、齐射、投射物已实现基础版
- 自动战斗默认 5 打 3，约 15 秒出结果
- 占位矩形渲染 + 调试 HUD

## 运行

```bash
"D:/Godot_v4.7/Godot_v4.7-stable_win64.exe" --path .
```

窗口 1280x720，逻辑分辨率 640x360（整数 2x）。

## 测试

```bash
"D:/Godot_v4.7/Godot_v4.7-stable_win64.exe" --headless --path . --script tests/test_sim.gd
```

覆盖：出兵/推进、跨路不交战、近战伤害、投射物、破甲/盾墙/攻城被动、法师溅射、基地扣血与胜负、默认战斗可结束、确定性。

## M1 调试按键

| 按键 | 行为 |
|---|---|
| `1` / `2` | 上路生成 玩家剑盾 / 敌方剑盾 |
| `3` / `4` | 上路生成 玩家弓箭手 / 敌方弓箭手 |
| `5` / `6` | 下路生成 玩家剑盾 / 敌方剑盾 |
| `R` | 重置并重新开始默认战斗 |
| `Esc` | 退出 |
