# 12 地图格式与调试编辑器（M7）

> 状态：`首版`：俯视节点图（单基地）+ 调试编辑器 ｜ 关联：[06-技术架构](06-技术架构.md)、[07-路线图](07-路线图.md)、[11-数值表](11-数值表与调参.md)
> TL;DR：地图是 v2 节点图；单玩家/单敌方基地，多出生路线/交汇/多向。战斗用 `MapGraph` Dijkstra；旧 v1 两路 JSON 可编译。调试编辑器 F3 或 `--map-editor`；玩家地图库/多基地后置。

## 地图 JSON v2

```json
{
  "version": 2,
  "id": "greyhaven_crossroads",
  "name_cn": "灰港十字路",
  "world": { "width": 1600.0, "height": 900.0 },
  "nodes": [
    { "id": "p_base", "type": "base", "team": 0, "name_cn": "灰鸦营地", "pos": [140, 450] },
    { "id": "e_base", "type": "base", "team": 1, "name_cn": "赤旗营地", "pos": [1460, 450] },
    { "id": "j_north", "type": "junction", "pos": [760, 280] }
  ],
  "edges": [
    { "id": "p_jn", "from": "p_base", "to": "j_north", "width": 80, "name_cn": "北路" },
    { "id": "jn_e", "from": "j_north", "to": "e_base", "width": 72, "name_cn": "北线" }
  ],
  "spawns": [
    { "id": "north", "team": 0, "base": "p_base", "entry": "p_jn", "name_cn": "北路" },
    { "id": "enemy_north", "team": 1, "base": "e_base", "entry": "jn_e", "name_cn": "敌方北路" }
  ]
}
```

- 每队恰好 1 个 base 节点；`team` 0/1。
- `nodes[].type = base|junction|waypoint`；`pos` 世界坐标。
- `edges[]` 无向；`width` 决定容量（默认 `floor(width/12)`，上限 12）；可选 `capacity` 覆盖；`polyline` 可选（省略=两端直线）。
- `spawns[]`：可选；`base+entry` 定义玩家/敌方出生口；省略时自动从基地相邻边生成。
- 路径由出生边 + `MapGraph.shortest_path` 动态计算；不需要手写 route 路径。
- 旧 v1 两路地图自动编译成图（基地节点 + 每条路一条直边 + 出生口），用于旧测试/自定义地图过渡。

## 校验

启动、导出前、编辑器 F8 都使用 `MapData` 校验：

- 每队唯一基地；节点/边/出生口 id 唯一。
- 边端点存在、长度合法、宽度 24–200；出生口 entry 连接对应基地。
- 玩家基地到敌方基地连通；出生口可达。
- 波次 route/lane 引用有效；unit id 存在。
- 地图错误会阻止 `validate_data` 导出。

```bash
"D:/Godot_v4.7/Godot_v4.7-stable_win64.exe" --headless --path . --script tools/validate_data.gd
```

## 调试编辑器

入口：

- 调试版：关卡选择按 `F3`。
- 任意版本：`SimpleGame.exe --map-editor`。

操作：

| 输入 | 行为 |
|---|---|
| 点击节点/边 | 选择 |
| 拖动节点 | 改位置，自动重算相连直边 |
| `N` | 鼠标位置新增交汇点 |
| `C` + 点击另一节点 | 从选中节点连一条新边 |
| `B` | 节点类型 普通→玩家基地→敌方基地→普通（同队只保留一个基地） |
| `[` / `]` | 选中边宽度 -4 / +4 |
| `Delete` / `Backspace` | 删除选中节点或边 |
| `F5` | 校验并写回 `res://data/maps/*.json`（PCK 只读时回退 `user://maps/`） |
| `F8` | 校验（并重建出生口） |
| `F9` | 重载 |
| `Tab` | 切换 `data/maps/*.json` |
| `Esc` | 返回关卡选择 |

右侧只读显示节点/边/路线数、选中信息、校验状态和引用该地图的委托波次。M7 不开放玩家地图库、导入/导出、撤销、多基地编辑；这些留 M8。

## 运行时接入

- `GameData._load_maps()` 加载所有委托/无尽引用地图并缓存、校验；地图错误阻止导出。
- `BattleSim` 用 `MapGraph` 计算路径；单位有 pos/edge/s/path/route；可反向/换路。
- 每边容量按宽度；满员节点排队；station_rank 决定入路顺序/前后站位。
- 快照带节点/边/出生口/路线路径/容量/集结点；HUD/2D 小地图/相机均按地图数据。
- 地图校验失败：`tools/validate_data.gd` 非 0；游戏仍回退默认图，但导出前必须修好。
