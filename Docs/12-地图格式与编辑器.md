# 12 地图格式与调试编辑器（M6）

> 状态：`首版`：两路直线地图 + 调试编辑器 ｜ 关联：[06-技术架构](06-技术架构.md)、[07-路线图](07-路线图.md)、[11-数值表](11-数值表与调参.md)
> TL;DR：M6 只数据化 **两条直线路**。地图是 JSON，战斗仍是 `lane + x` 一维移动；多基地/交汇/多向/真图在 M7。调试编辑器只在调试版 F3，或发行版用 `--map-editor` 启动。

## 文件

```text
data/maps/greyhaven_road.json   # 委托 1/2
data/maps/mistmarsh_road.json   # 委托 3/无尽
data/levels/*.json              # "map": "res://data/maps/....json"
sim/map_data.gd                 # 读取/规范化/校验
main/map_editor.gd/.tscn        # 调试编辑器
```

## 地图 JSON

```json
{
  "version": 1,
  "id": "greyhaven_road",
  "name": "Greyhaven Outer Road",
  "name_cn": "灰港外环大道",
  "world": { "width": 1600.0, "height": 360.0 },
  "bases": [
    { "id": "player", "team": 0, "name_cn": "灰鸦营地", "x": 80.0 },
    { "id": "enemy", "team": 1, "name_cn": "赤旗营地", "x": 1520.0 }
  ],
  "routes": [
    {
      "id": 0,
      "name_cn": "北道",
      "y": 110.0,
      "player_spawn_x": 92.0,
      "enemy_spawn_x": 1508.0,
      "segments": [
        { "from": 80.0, "to": 720.0, "width": 80.0 },
        { "from": 720.0, "to": 1120.0, "width": 64.0 },
        { "from": 1120.0, "to": 1520.0, "width": 80.0 }
      ]
    }
  ]
}
```

- `world`：世界宽高；M6 默认 1600×360。
- `bases`：必须有 team 0/1；`x` 是左右基地中心。M6 仍是单玩家基地。
- `routes`：M6 必须恰好两条（第二条省略以节省篇幅）；每条是直线。
- `segments`：按 x 分段的路宽，段之间必须连续覆盖左右基地，不能有缺口/重叠。
- `player_spawn_x` / `enemy_spawn_x`：出生点；编辑器拖动基地时会按基地 ±12 自动更新，也可手改。
- 路宽当前只影响绘制、拾取和可读性，不改变战斗命中/寻路；容量/拥挤留给 M7。

## 校验

启动、导出前、编辑器 F8 都使用 `MapData` 校验：

- base 0/1 存在；玩家基地在敌方左侧且距离 ≥ 240。
- 两条路线；Y 坐标合法且相距 ≥ 40。
- 段宽 24–160；段按 x 排序、覆盖基地、无缺口/重叠。
- 基地/出生点在边界内；路线宽度不越过世界上下边界。

数据校验：

```bash
"D:/Godot_v4.7/Godot_v4.7-stable_win64.exe" --headless --path . --script tools/validate_data.gd
```

## 调试编辑器

入口：

- 编辑器/调试版：关卡选择按 `F3`。
- 任意版本：命令行加 `--map-editor`，例如 `SimpleGame.exe --map-editor`。

操作：

| 输入 | 行为 |
|---|---|
| 左键点击基地/道路 | 选择对象 |
| 拖动基地 | 改 x；自动调整首/末宽度段和出生点 |
| 拖动道路 | 改当前宽度段的宽度 |
| `Shift`+拖动道路 | 改整条路线的 Y |
| `N` | 在鼠标 x 处切分当前宽度段 |
| `Delete` / `Backspace` | 删除当前段（合并到相邻段） |
| `[` / `]` | 当前段宽度 -4 / +4 |
| `F5` | 写回 `data/maps/*.json`（PCK 只读时回退到 `user://maps/`） |
| `F8` | 校验 |
| `F9` | 重载当前地图 |
| `Tab` | 切换 `data/maps/*.json` |
| `Esc` | 返回关卡选择 |

右侧只读显示引用当前地图的委托与波次时间，便于改路宽时检查节奏。M6 不编辑波次时间、不导入玩家地图。

## 运行时接入

- `GameData._load_maps()` 读取所有委托/无尽引用的地图并缓存、校验；缺失地图会阻止数据校验。
- `BattleSim` 从 `MapData` 读取世界宽高、基地 x、路线数量/出生点；仍是 `lane + x`。
- 快照带 `map`（世界/基地/路线/宽度段）与 `player_base_x/enemy_base_x/world_width/lane_count`。
- `BattleView` 按宽度段绘制道路、基地、出生点；`CameraRig` 按世界宽度限制；小地图按快照世界宽度换算。
- 地图校验失败：`tools/validate_data.gd` 非 0；游戏仍会回退到默认两路数据，但导出前必须修好。

## M6 明确不做

- 交汇、多基地、多向移动、A*/图寻路、边容量。
- 玩家地图编辑器/导入、Godot 插件、波次时间线编辑。
- 2.5D 高度/遮挡；M7 只考虑装饰性高度。
