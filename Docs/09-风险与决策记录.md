## M3 自测记录（2026-10-29）

| 项 | 内容 |
|---|---|
| 构建 | M3：1600 宽战场、跟随镜头、小地图、推进线、框选/移动/驻守/返回、3 关 |
| 自动试玩 | 三关均可通关；第 1 关基地 18/20，第 2 关 3/20，第 3 关 3/20 |
| 关键发现 | 推进线默认在门口，玩家必须主动前压；否则敌方远程会在射程外停住形成僵持 |
| 关键发现 | 第 3 关初版波次过强，已下调约 30% 后可通过；仍为三关最高难度 |
| 待人工验证 | 框选/右键移动/推进线的可理解性；小地图切路是否顺手；镜头跟随是否晕 |
| 未做 | 外部 3 人试玩（M3 退出标准要求；当前只有自动试玩/自测） |
