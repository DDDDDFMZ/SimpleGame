## M7.2 决策

| ID | 决策 | 理由 | 否决备选 |
|---|---|---|---|
| M7.2-01 | 索敌一律限制在自身射程 120%，移除同边无限 aggro | 用户指定；解决远距离拉怪/追到地图尽头 | 同边无限/全图 aggro |
| M7.2-02 | 不用“簇内最远射程”作为移动/追击范围，只用于告警与攻击者共享 | 避免近战被远程队友拖去远追；保持单位角色边界 | 全簇按最远射程接敌 |
| M7.2-03 | 受击支援只共享 2.5 秒内实际攻击者，不共享普通当前目标 | 用户指定“受到攻击时”；共享目标会形成安全区集火，压垮近战线 | 共享所有目标/无支援 |
| M7.2-04 | 友军簇按 assist_radius 传递性连通，全簇链接 | 用户要求 A-B-C 链接成整体；<100 单位成本可接受 | 只近邻一层/固定小队 |
| M7.2-05 | 横向位置与容量槽位解耦：默认中线，重叠才展开，双方各半幅 | 用户指定；避免单单位偏在槽位、后排错位 | 槽位=视觉位置/固定队伍半边 |
| M7.2-06 | 队列按 squad_rank/station_rank 排序显示，队首在节点；队列轴沿目标边反向 | 修复后排出现在前排；玩家能读懂 | 固定网格/先到先显示 |
| M7.2-07 | queue 卡死用结构性修复+超时绕行，不直接放大容量 | 保留宽度压力；解决入口节点/陈旧队列根因 | 加宽/取消容量 |
| M7.2-08 | 右键移动改为移动优先：途中可攻击射程内目标，到达恢复自动 | 用户要求战斗中可控调动；不牺牲全部输出 | 移动完全禁攻击/攻击永远优先 |
