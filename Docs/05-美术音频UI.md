# 05 美术、音频与 UI（M6）

> 状态：`首版` 占位美术 + 全中文 HUD ｜ 关联：[01-核心循环](01-核心循环.md)、[02-兵种](02-战斗与兵种.md)、[12-地图与编辑器](12-地图格式与编辑器.md)
> TL;DR：640x360 逻辑画布；8 张职业卡；B 打开协会面板（声望 + 三协会）；选中面板按协会/攻型/甲型/职业分组；小地图拖选/右键/推进线；战斗 HUD、关卡选择、地图编辑器全中文。

## 美术方向

- 经典魔幻中世纪 + 轻卡通像素；M4 仍是占位矩形，M5 换像素。
- 玩家蓝、赤旗红；目标敌人金色边框；精英金色外框。
- 640x360，整数 2x 到 1280x720；Nearest。
- 中文 UI 使用 SystemFont（微软雅黑/Noto Sans CJK），不引入外部字体；M5 再统一像素字体。

## M6 信息层/中文

- C1 自动 checklist：B -> 建交 -> 招募 -> 推进线 -> 目标 -> 晋升；`F2` 开关。
- `F1` 战地指南 2 页（←/→ 翻页）：资源链/指挥/选中面板；8 职业/克制/目标/预览；打开时暂停。
- 卡牌右上显示攻/甲缩写；hover tooltip：生命/每秒伤害/射程/被动/克制/解锁条件，全中文。
- 右上“下一波 xx秒”面板：路线、单位数量、目标标记。
- 结算：漏怪按单位 Top3、花费（招募/协会/晋升）、未花金币、目标数。
- 选中信息面板：见下节。
- 伤害数字仍为 P1（未做）；先靠 tooltip/波次/结算原因。

## 选中信息面板（M6）

- 选中 1 名：名称、协会、定位/攻型/甲型、位置、状态、操作提示。
- 选中多名：数量、合计生命、平均位置；四个分类 tab：
  - 协会（铁誓/绿荫/星环）
  - 攻型（近战/远程/攻城）
  - 甲型（轻甲/重甲）
  - 职业（剑士/矛兵/…）
- 每个分组显示数量与合计生命；点击分组把选择切换为该组，再右键移动或 `H` 驻守 / `R` 归线。
- 面板位置右下（小地图下方），Company/F1/暂停/结算时隐藏，避免遮挡。

## Company 面板（B）

- 顶部：声望等级、名望进度、晋升花费、“晋升”按钮。
- 三行协会：名称、当前关系（未建交/关系 N/未解锁）、下一级费用/兵力/解锁职业、人情/已雇。
- 点击行：当前协会下一级建交/升级。
- 无建筑面板；无农场/兵营。

## 小地图操作

- 左键点击：切路 + 镜头跳转。
- 左键拖拽：按路/x 范围框选己方单位。
- 右键：有选中单位则移动到点击 x。
- `Shift+右键`：设置该路推进线。
- 显示：基地、单位、目标金点、推进线、镜头范围；当前路高亮。

## 框选

- 拖动起点在按下瞬间转世界坐标并保存；镜头移动后选框仍贴地图。
- 选框由世界视图绘制；松开后按世界矩形选中。
- 点击空地清空选择；Shift 加选。

## 关卡选择

- 标题“灰港委托”；副标题“灰鸦小队 · 冒险者协会委托板”。
- 3 张委托卡：中文名、简报、星级、可用协会；锁定显示“尚未解锁”。
- 无尽卡：最佳分/波数；通关委托 3 解锁。
- 底部：三协会人情加成；`1-3`/点击开始，`E` 无尽，`Esc` 退出。
- 调试版底部显示 `F3 地图编辑器（调试）`；发行版可用 `--map-editor` 启动。

## 结算/暂停

- 结算：委托完成/防线失守/平局、星级、悬赏、基地、三个按钮（重试/下一关/委托列表）。
- 无尽：本轮结束、波数/分数。
- 暂停：空格继续、Ctrl+R 重试、Esc 返回委托列表。
- 当前无音频；后续接免费素材。

## 美术量（M6 占位）

- 8 职业色块 + 攻击类型 glyph；目标/精英金框。
- 环境为双路 + 宽度段 + 基地；道路宽度由地图 JSON 控制；未做像素 tile/动画。
