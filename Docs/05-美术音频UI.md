# 05 美术、音频与 UI（M7.3）

> 状态：`首版` 占位美术 + 全中文 HUD ｜ 关联：[01-核心循环](01-核心循环.md)、[02-兵种](02-战斗与兵种.md)、[12-地图与编辑器](12-地图格式与编辑器.md)
> TL;DR：640x360；俯视节点图；8 张职业卡；协会面板；2D 小地图+缩放；碰撞箱/路宽分排；统一设置界面；暂停菜单/存档备份；全中文；测试无音频时使用 Dummy 驱动。

## 美术方向

- 俯视 2D 占位：深色地形网格、粗道路、圆形节点/基地、矩形单位。
- 玩家蓝、赤旗红；目标金色菱形；精英金色外框。
- 640x360，整数 2x；Nearest。
- 中文 UI 使用 SystemFont（微软雅黑/Noto Sans CJK/SimHei），M8 再统一像素字体。

## 战斗 HUD

```text
金币 200 (+6.0/秒) 兵力 8/8 基地 20/20
第1/4波 20秒 声望 R0 功勋 0/1 晋级40金 悬赏0/4
路线 北路 3/6 Q/E换路 滚轮缩放 ×0.8 F1指南
[2D 小地图：道路/节点/基地/单位/相机框/缩放按钮]
[1 剑士] [2 矛兵] ... [8 牧师]
```

- 顶部状态限制在左侧（小地图/波次面板占右侧）；下一波显示路线/数量/目标。
- 8 张卡 74x48；未建交/关系不足显示中文要求；金币/兵力不足/冷却遮罩。
- 相机缩放 0.5–1.5×；小地图相机框随位置/缩放同步。
- 框选锚点可在道路外；选中命中使用单位真实 2D 位置。
- 单位：按 `body_width/body_height` 绘制碰撞箱 + 攻型 glyph + 血条；默认道路中线，同纵向位置多单位自动横向展开，超出并行数自动排到后一排。
- 右键移动中的小队显示“机动”状态（移动优先）；到达后恢复自动战斗。

## 2D 小地图

- 170x96 等比显示节点图；道路、节点、基地、单位、目标金点。
- 相机框按 viewport/(2×zoom) 计算。
- 左键点击：镜头跳转；左键拖：世界矩形框选；右键：移动选中；Shift+右键：设当前路线集结点。
- `-`/`+` 按钮/滚轮缩放；顶部显示当前 birth route 在路人数与并行数。

## 选中信息面板（M7.3）

- 单选：名称/协会/定位/攻甲/位置/边/状态/编队（路线/队长/速度/间距/状态）；右键移动、H/R。
- 多选：数量、合计生命、编队摘要；分类 tab 协会/攻型/甲型/职业。
- 点击分组把选择切换为该组，再右键移动/H/R；分组移动会重新创建该路线编队。
- 面板位于小地图下方，Company/F1/暂停/结算时隐藏。

## 协会议会（B）

- 顶部：声望、功勋（累计）、晋级花费、下一级完整收益、晋级按钮。
- 三行协会：中文名、关系、定位、下一级费用/兵力/解锁职业、人情。
- 未满足 `rank_gate` 时显示“需声望 R1/R2”并阻止点击。
- 人情显示实际数值（从 `balance.json` 读取）。

## 暂停菜单（Space）

- 模态：继续、战地指南、备份进度、设置、重开本局（确认）、返回委托（确认）。
- 暂停时 HUD/世界/相机输入全部锁定；F1 从暂停打开指南，关闭回到暂停；打开设置时保持暂停，关闭回暂停菜单。
- 设置界面：显示（默认缩放/窗口缩放/全屏）、站位顺序（8 行上/下）、操作参考、恢复默认设置；唯一文件 `user://settings.json`。
- 关卡选择右上“设置 [O]”打开同一面板。
- 友方单位相向行进时自动左右让位；敌方经过不触发横向避让，保持阵型或进入攻击。路径总人数不设上限。

## 关卡选择/存档/设置

- 标题“灰港委托”；3 委托卡+无尽卡；锁定/星级/人情；右上“设置 [O]”。
- `S` 打开存档面板：主档路径、最近备份（日期/委托数/星数）、手动备份、恢复选中、新存档、关闭；恢复/新档二次确认。
- 新存档前自动备份；设置独立于进度，恢复/新档不覆盖设置。

## 结算/结果

- 委托完成/防线失守/平局；星级、悬赏、基地、漏怪 Top3、花费、剩余金币。
- 无尽：本轮结束、波数/分数；按钮重试/下一关/委托列表。
- 无音频；项目音频驱动设为 Dummy，避免 Windows WASAPI 的 GetBufferSize/Start failed 报错。M8 接音频时再切回真实驱动/设备回退。
