# 05 美术、音频与 UI（M4）

> 状态：`首版` 占位美术 + 中文关卡选择 ｜ 关联：[01-核心循环](01-核心循环.md)、[02-兵种](02-战斗与兵种.md)
> TL;DR：640x360 逻辑画布；8 张职业卡；B 打开 Company 面板（声望 + 三协会）；小地图支持拖选/右键移动/推进线；关卡选择/结算中文。

## 美术方向

- 经典魔幻中世纪 + 轻卡通像素；M4 仍是占位矩形，M5 换像素。
- 玩家蓝、赤旗红；目标敌人金色边框；精英金色外框。
- 640x360，整数 2x 到 1280x720；Nearest。
- 中文 UI 使用 SystemFont（微软雅黑/Noto Sans CJK），不引入外部字体；M5 再统一像素字体。

## 战斗 HUD

```text
GOLD 200 (+6.0/s)  CAP 8/8  BASE 20/20  WAVE 1/4  NEXT 20s
REP R0  FAME 0/1  PROMOTE 40g  TARGETS 0  CONTRACT 1
1-8 recruit  B company  Q/E lane  drag select  RMB move  Shift+RMB line  F follow  Ctrl+R retry
[小地图：L1/L2 条带、基地、单位、目标金点、推进线、镜头框]
[1 剑盾] [2 长矛] [3 骑士] [4 弓手] [5 盗贼] [6 弩炮] [7 法师] [8 牧师]
```

- 8 张卡，每张 74x48；未建交/未升级显示 `IRON T1` 等要求；锁定卡不显示成本。
- 冷却/金币/上限不足有遮罩。
- 目标敌人：金色方框+菱形标记；小地图金点。

## M5 信息层

- C1 自动 checklist：B -> 建交 -> 招募 -> 推进线 -> 目标 -> PROMOTE；`F2` 开关。
- `F1` Field Guide：资源链、8 职业、克制、目标/精英、操作；打开时暂停。
- 卡牌右上显示攻型/甲型缩写；hover tooltip：HP/DPS/射程/被动/Good vs/Weak vs/解锁条件。
- 右上 “NEXT WAVE” 面板：时间、lane、单位数量/护甲/目标标记；有小地图威胁色。
- 目标：顶部 `TARGETS x/total`；checklist/Field Guide 解释金目标 -> +15g +1 Fame。
- 结算：漏怪按单位 Top3、花费（单位/协会/晋升）、未花金币、目标数。
- 伤害数字为 P1（当前未做）；先靠 tooltip/波次/结算原因。

## Company 面板（B）

- 顶部：声望 Rank、名望进度、晋升花费、PROMOTE 按钮。
- 三行协会：名称、当前 T 级（未建交/NOT CONTACTED）、下一级费用/上限/解锁职业、人情/使用次数。
- 点击行：当前协会下一级建交/升级。
- 无建筑面板；无农场/兵营。

## 小地图操作

- 左键点击：切路 + 镜头跳转。
- 左键拖拽：按路/x 范围框选己方单位。
- 右键：有选中单位则移动到点击 x。
- `Shift+右键`：设置该路推进线。
- 显示：基地、单位、目标金点、推进线、镜头范围；当前路高亮。

## 框选

- 拖动起点在按下瞬间转世界坐标并保存；镜头移动后选框仍贴地图。
- 选框由世界视图绘制；松开后按世界矩形选中。
- 点击空地清空选择；Shift 加选。

## 关卡选择

- 标题“灰港委托 / GREYHAVEN CONTRACTS”。
- 3 张契约卡：中文名、简报、星级、可用协会；锁定显示条件。
- 无尽卡：最佳分/波数；通关契约 3 解锁。
- 底部：三协会人情加成；`1-3`/点击开始，`E` 无尽，`Esc` 退出。

## 结算/暂停

- 结算：胜利/失败、星级、目标、基地、三个按钮（重试/下一/契约列表）。
- 无尽：RUN OVER、波数/分数。
- 暂停：Space 继续、Ctrl+R 重试、Esc 返回契约列表。
- M4 无音频；M5 接免费素材。

## 美术量（M4 占位）

- 8 职业色块 + 攻击类型 glyph；目标/精英金框。
- 环境仍是两条路 + 基地；M5 才做像素 tile/动画。
