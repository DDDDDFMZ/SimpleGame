# 05 美术、音频与 UI

> 状态：`首版` ｜ 关联：[02-战斗与兵种](02-战斗与兵种.md)、[06-技术架构](06-技术架构.md)、[08-待办清单](08-待办清单.md)
> TL;DR：640x360 像素画布，整数放大；6 兵种各 14 帧动画；敌军只换色。先占位素材跑通，再统一重绘。

## 美术方向

- 风格：经典魔幻中世纪 + 轻卡通像素；不写实、不暗黑血腥。
- 可读性优先：单位轮廓、武器、甲型必须在 640x360 下 1 秒内分辨。
- 玩家阵营蓝色主色，敌方红色主色；同一兵种靠盾/矛/弓/法杖/马/投石机区分，不靠颜色区分。
- 环境低饱和，单位和 VFX 高饱和，保证战场焦点。
- 不做 HD2D、法线光照、景深（`远期` 可加轻量光照）。

## 分辨率与像素规格

| 项 | 规格 |
|---|---|
| 逻辑分辨率 | **640 x 360**（16:9） |
| 放大 | 整数倍：3x -> 1920x1080；2x -> 1280x720 |
| 纹理过滤 | Nearest（关闭平滑） |
| 像素网格 | 16x16 基础 tile |
| 单位尺寸 | 32x32（投石车 48x32） |
| 基地 | 128x96 |
| 兵营/农场 | 48x48（含 3 个等级外观） |
| 路高 | 约 100 px；两条路 + HUD + 出兵栏刚好填满 360 |
| UI 字号 | 中文最小 12 px；标题 16-24 px |

> 640x360 而非 480x270：中文 UI 在 480x270 下过小，640x360 可读性与像素感平衡。

### 调色板（32 色以内）

| 用途 | 色值 | 说明 |
|---|---|---|
| 深色背景 | `#1E1A2B` | 夜间/阴影 |
| 地面 | `#5A4A3A` / `#6E5A45` | 两条路区分明度 |
| 玩家蓝 | `#3B6EA5` | 旗帜、选中高亮 |
| 玩家亮蓝 | `#6FA8DC` | 血条、UI |
| 敌方红 | `#A53B3B` | 旗帜、敌方血条 |
| 敌方亮红 | `#E06666` | 危险提示 |
| 金币黄 | `#D9A441` | 金币、可负担 |
| 羊皮纸 | `#E8D5A9` | 面板底色 |
| 草绿 | `#4F7A4A` | 环境 |
| 魔法紫 | `#7A5AA5` | 法师、魔法 VFX |
| 警示橙 | `#E08A3C` | 波次警告 |
| 禁用灰 | `#6B6B6B` | 不可用按钮 |

- 所有 UI 文本对比度 ≥ 4.5:1（深底浅字/浅底深字）。
- 色盲友好：单位类型同时用形状/武器区分；血条用长度+数字，不只靠红绿。

## 动画预算

| 单位 | 动画 | 帧数 | 说明 |
|---|---|---:|---|
| 剑盾兵 | idle / walk / attack / death | 2 / 4 / 4 / 4 | 盾牌轮廓明显 |
| 长矛兵 | idle / walk / attack / death | 2 / 4 / 4 / 4 | 长矛长度夸张 |
| 弓箭手 | idle / walk / attack / death | 2 / 4 / 4 / 4 | 拉弓动作清晰 |
| 法师 | idle / walk / attack / death | 2 / 4 / 4 / 4 | 法杖发光 |
| 骑士 | idle / walk / attack / death | 2 / 4 / 4 / 4 | 马匹/披风 |
| 投石车 | idle / walk / attack / death | 2 / 4 / 4 / 4 | 轮子/投臂 |

- 每兵种 14 帧 x 6 = 84 帧；敌军换色复用，不新增帧。
- 建筑：农场/兵营各 3 级，每级 1 帧静态 + 升级 VFX；不做建造动画（首版）。
- 环境：2 套地面 tile（上路/下路可同套换色）、树/石头/栅栏/火把等 8-12 个 props。
- UI：9-slice 面板、按钮 3 态、图标 6 兵种 + 金币/人口/血量/波次/建筑。

## VFX 清单

| VFX | 用途 | 复杂度 |
|---|---|---|
| 命中火花 | 近战命中 | 低 |
| 箭矢/石弹 | 远程投射物 | 低 |
| 魔法弹/爆点 | 法师攻击/溅射 | 中 |
| 死亡烟雾 | 单位死亡 | 低 |
| 金币飘字 | 击杀奖励 | 低 |
| 建造/升级光 | 建筑完成 | 低 |
| 波次警告 | 下一波提示 | 低 |
| 基地受击 | 基地掉血 | 中 |
| 选中圆环/血条 | 操控反馈 | 低 |
| 胜利/失败 | 结算 | 低 |

VFX 用帧动画或简单 shader/粒子；不做复杂物理粒子。

## UI 线框

### 战斗 HUD

```text
┌──────────────────────────────────────────────────────────┐
│ 金币 120 (+4/s)   人口 6/10   基地 20/20   波次 3/7 00:12 │
│                                                          │
│                 [ 上路战场 / 镜头区域 ]                   │
│                                                          │
│                 [ 下路战场 / 小地图切换 ]                 │
│                                                          │
│ [1 剑盾30] [2 长矛35] [3 弓40] [4 法60] [5 骑70] [6 投80] │
│ [B 建筑]                                      [空格 暂停] │
└──────────────────────────────────────────────────────────┘
```

- 左上：金币、收入、人口、基地血量。
- 中上：波次进度、下一波倒计时、波次警告。
- 右上：小地图（两路条带 + 基地血量 + 波次）。
- 底部：6 个出兵卡 + 建筑按钮 + 暂停。
- 选中单位时显示：血条、兵种名、人口、当前状态（推进/驻守/移动）。

### 出兵卡

```text
┌────────┐
│  图标  │  剑盾兵
│ 30金   │  人口 1
│ [1]    │  冷却遮罩
└────────┘
```

- 不可负担：成本数字变红，卡片变暗。
- 人口满：卡片变红并显示“人口满”。
- 冷却：从下往上的灰色遮罩 + 剩余秒数。
- 悬停：显示完整属性（HP/DPS/攻型/甲型/被动）。

### 建筑面板（B）

```text
┌────────────────────────────┐
│ 后勤                        │
│ [农场 A Lv1] [农场 B 空]    │
│ [兵营·上 Lv1] [兵营·下 空]  │
│ 选择槽位 -> 建造/升级/取消  │
└────────────────────────────┘
```

- 槽位显示等级、效果、成本、是否可负担。
- 建造/升级即时生效；按钮点击后关闭面板或留在面板（设置项）。

### 小地图

```text
┌──────────────────────────────┐
│ 上路  ███████░░░░  18/20      │
│ 下路  ████░░░░░░░  18/20      │
│ 波次 3/7   下一波 00:12       │
└──────────────────────────────┘
```

- 蓝色/红色块表示双方兵力规模；三角标表示推进线。
- 点击条带切路；`Q/E` 同步高亮。
- 首版不显示敌方兵种，只显示数量级。

### 结算

```text
        ★ ★ ☆
        第 3 关 群鸦
   基地 16/20   击杀 42   获得金币 680
   [重试]  [下一关]  [返回关卡选择]
```

- 星级动画 0.5 秒；同时显示失败原因（基地血量/漏怪数）。
- 失败界面：`重试` 为主按钮，`返回` 为次按钮。

### 关卡选择

```text
第1关 ★★★   第2关 ★★☆   第3关 ★☆☆
第4关 锁定   第5关 锁定   无尽 未解锁
```

- 线性节点；锁定关卡显示解锁条件。
- 每关显示标志性敌人图标与最佳星级。

### 暂停/设置

- 继续、重试、设置、返回关卡选择。
- 设置：音乐音量、音效音量、UI 缩放、语言（首版中文）、屏幕震动开关。
- 暂停时战场变暗但不冻结 UI；仍可看出兵/建筑面板（按 `Space` 恢复后执行）。

## 音频

### 音效（约 15-20 个）

| 类别 | 音效 |
|---|---|
| UI | 点击、悬停、错误/不可用、建造、升级 |
| 出兵 | 剑盾/长矛/弓/法/骑/投石各 1 个出生音（可复用 3 个） |
| 战斗 | 剑击、矛刺、弓射、箭命中、魔法施放、魔法命中、投石发射、投石命中 |
| 单位 | 死亡、受击（可选） |
| 系统 | 金币、波次警告、基地受击、胜利、失败 |

### 音乐

| 曲目 | 用途 | 要求 |
|---|---|---|
| `menu_theme` | 主菜单/关卡选择 | 60-90 秒循环， calm |
| `battle_theme` | 战斗 | 90-120 秒循环，中速，有鼓点 |
| `boss_layer` | 首领波（`后期`） | 可叠加层 |

- 格式 OGG Vorbis；循环点用音频编辑器标注。
- 首版用 CC0/免费素材，记录来源与许可证；Demo 后再决定购买/委托。
- 音量默认：音乐 0.8、音效 0.9；设置可调。

## 占位与替换流程

1. 先用纯色块/几何图形 + 文字标签做占位（M1-M2）。
2. 用免费像素素材包替换单位/环境（M3），统一调色板。
3. M5 统一重绘 6 兵种与建筑；敌军用 palette swap/modulate 换色。
4. 所有资源记录：文件名、来源 URL、许可证、作者。
5. Godot 导入：PNG、Nearest、关闭 mipmap；SpriteFrames 或 AnimationPlayer。

## 本地化

- 首版中文，所有 UI 文本走 key 表（CSV/JSON），不硬编码。
- 英文在 Demo 后补；文本长度预留 1.3 倍。
- 字体：使用支持中文的像素字体或开源字体；确认商用许可。

## 可访问性

- UI 缩放 1x/1.25x/1.5x。
- 屏幕震动开关；闪烁效果可关闭。
- 色盲友好：图标形状 + 文字，不只靠颜色。
- 暂停随时可用；失败可立即重试。
- 首版不做键位重绑；`后期` 加。

## Open Questions

- 640x360 下中文 12px 是否清晰？需要实际字体测试。
- 6 兵种 14 帧是否够？骑士/投石车可能需要更多帧。
- 敌军换色用 shader 还是单独贴图？先用 modulate，确认可读性。
- 免费素材风格是否统一？M3 试拼后决定是否提前重绘。
- 是否需要战斗中的单位语音/喊叫？首版不做，避免音频量。
