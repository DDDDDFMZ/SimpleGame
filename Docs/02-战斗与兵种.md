# 02 战斗与兵种（M7）

> 状态：`首版`：8 职业、3 协会、节点图战斗 ｜ 关联：[03-经济](03-经济与建筑.md)、[04-关卡](04-关卡与模式.md)、[12-地图](12-地图格式与编辑器.md)
> TL;DR：8 职业；单位沿节点图道路移动，可反向/换路；战斗用 2D 距离；道路宽度限制每方人数，满员节点排队；站位顺序决定入路优先级与集结点前后位置。软克制不变。

## 战斗规则

- 单玩家基地 + 单敌方基地；地图为节点/边图，多个出生口与交汇。
- 状态：`advance / engage / attack / hold / queue / dead`。
- 单位有 `pos / edge_id / edge_s / path / route_id / station_rank`；路径由 `MapGraph` Dijkstra 计算。
- 索敌：同一条边上的敌人无视 aggro 距离（沿路可见）；不同边只在射程/aggro 内互相攻击。
- 贴敌后锁定；丢失 0.35 秒后恢复移动；战斗优先于移动/集结点。
- `H` 驻守：不追击，只打射程内；`R` 返回所属路线集结点。
- 到达集结点/移动点会吸附；可沿边反向移动。
- 玩家单位到达敌方基地附近会驻守（防守关）；敌人到达玩家基地附近漏怪。
- 所有波次出完后，未手动驻守的己方单位会主动寻敌清场，避免残敌卡关。
- 伤害顺序：基础伤害 × 攻/甲克制 × 被动 × 修正；无护甲减伤、暴击、闪避。
- 基地血量 20；普通漏怪 1、精英 2。

## 攻型/甲型软克制

| 攻型 \ 甲型 | 轻甲 | 重甲 |
|---|---:|---:|
| 近战 | 1.5x | 0.75x |
| 远程 | 1.0x | 1.0x |
| 攻城 | 0.5x | 1.5x |

## 道路容量与站位

- 每条边容量 = `clamp(floor(width / 12), 1, 12)`；可在边数据写 `capacity` 覆盖。
- 容量按**每方**计算；双方可同时进入同一条边。
- 目标边满员时单位停在节点排队；容量空出后按 `station_rank`（默认）→到达顺序进入。
- `units.csv` 的 `station_rank` 给默认顺序；玩家可在暂停菜单的“站位顺序”上/下调整并保存。
- 站位顺序同时影响集结点前后站距（`station_spacing`）；不改变战斗数值。
- 当前默认：剑士 → 骑士 → 矛兵 → 盗贼 → 弓手 → 弩车 → 法师 → 牧师。

## 目标敌人

- 波次 `target: true`：金色边框 + 小地图金点。
- 击杀奖励：+15 金、+1 功勋；精英目标同时按精英赏金结算。
- 目标不是胜利条件；用于声望晋级。
