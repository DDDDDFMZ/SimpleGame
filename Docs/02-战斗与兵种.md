# 02 战斗与兵种（M7.2）

> 状态：`首版`：8 职业、3 协会、节点图战斗 ｜ 关联：[03-经济](03-经济与建筑.md)、[04-关卡](04-关卡与模式.md)、[12-地图](12-地图格式与编辑器.md)
> TL;DR：8 职业；单位沿节点图道路移动，可反向/换路；战斗用 2D 距离；索敌限定射程 120%；道路共享碰撞槽位，队列有序、默认中线、需要时横向成线；编队按最低速度/间距跟随；受击友军共享攻击者。软克制不变。

## 战斗规则

- 单玩家基地 + 单敌方基地；地图为节点/边图，多个出生口与交汇。
- 状态：`advance / engage / attack / hold / queue / dead`。
- 单位有 `pos / edge_id / edge_s / path / route_id / station_rank / squad_id / body_*`；路径由 `MapGraph` Dijkstra 在命令/节点决策时计算，正常移动 tick 不重跑。
- 索敌：所有单位只在自身 `attack_range × target_range_mult`（默认 1.2）内获取目标；同边不再无限追击，跨边远程只打射程内。
- 目标滞回：当前目标仍在 120% 窗口内则保持；超出后重选最近的可获取目标。
- 每个单位有碰撞箱 `body_width/body_height`；位置 = 道路中心线 + 法向横向偏移，用于绘制/选中/占位，不做刚体挤压。默认中线，只有同纵向位置多单位/避让时才横向展开。
- 自动接敌时战斗优先；玩家右键移动期间改为移动优先：沿路径前进并攻击射程内目标，到达后恢复自动战斗。
- 被攻击时记录 `last_attacker`：自身优先反击；附近友军通过 `assist_radius` 传递性链接成簇，簇内共享 2.5 秒内的攻击者。其他单位只在自身射程内开火，不改变路线、不追出射程。
- 簇内“射程最远单位”的 120% 视野用于共享告警，但不会把近战单位拉去远处追击。
- `H` 驻守：不追击，只打射程内；`R` 返回所属路线集结点。
- 到达集结点/移动点会吸附；可沿边反向移动。右键目标在身后/另一条路时，单位选择更近的当前边端点掉头，而不是绕到远端。
- 玩家单位到达敌方基地附近会驻守（防守关）；敌人到达玩家基地附近漏怪。
- 所有波次出完后，未手动驻守的己方单位会主动寻敌清场，避免残敌卡关。
- 伤害顺序：基础伤害 × 攻/甲克制 × 被动 × 修正；无护甲减伤、暴击、闪避。
- 基地血量 20；普通漏怪 1、精英 2。

## 攻型/甲型软克制

| 攻型 \ 甲型 | 轻甲 | 重甲 |
|---|---:|---:|
| 近战 | 1.5x | 0.75x |
| 远程 | 1.0x | 1.0x |
| 攻城 | 0.5x | 1.5x |

## 道路槽位、编队与站位

- 每条边槽位数 = `clamp(floor((width - 2*padding) / slot_width), 1, 24)`；可在边数据写 `capacity` 覆盖。默认 `road_slot_width=12`、`road_slot_padding=1`。
- 槽位由**双方共享**；每方优先使用自己半幅，宽度>=2 时相遇各让半边；槽满在节点排队。
- 排队优先级：同编队按 `squad_rank`（队首先入），否则按 `station_rank` → 到达顺序；队列按该顺序显示，队首在节点、队尾沿边向后。
- 队列超时（`queue_timeout`）后若存在替代路线则绕行；友军堵满时立即尝试替代边；目标在入口节点、队列条目丢失等陈旧状态会自愈。
- `units.json` 的 `station_rank` 给默认顺序；玩家可在设置（关卡选择 `O` / 暂停菜单）里上/下调整，保存到 `user://settings.json`。
- 站位顺序决定入路优先级和并排时的左右次序；不改变战斗数值。
- 集结点/部署点采用横线：同点单位默认中线，多单位按 `body_width` 横向展开；不再用 station_rank 拉成长列。
- 框选移动按路线分组编队：全队速度上限=该组最低 `speed`；队首按自身路径带路，后排沿队长轨迹按 `squad_spacing` 跟随；太近停止/反向，队尾落后过远队首短暂等待；偏离路线的成员进入汇合状态。到达后全队统一最终点并横向展开成战线。
- 队长死亡后下一 rank 提升并重算速度/轨迹；成员死亡重算最低速度；`H/R` 解散编队。快照/HUD 显示路线、队长、速度、间距、状态。
- 当前默认：剑士 → 骑士 → 矛兵 → 盗贼 → 弓手 → 弩车 → 法师 → 牧师。

## 目标敌人

- 波次 `target: true`：金色边框 + 小地图金点。
