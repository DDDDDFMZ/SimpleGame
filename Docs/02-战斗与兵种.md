# 02 战斗与兵种

> 状态：`首版` ｜ 关联：[01-核心循环](01-核心循环.md)、[03-经济与建筑](03-经济与建筑.md)、[04-关卡与模式](04-关卡与模式.md)
> TL;DR：1D 横版自动战斗。6 兵种，3 攻型 x 2 甲型软克制，每兵种 1 个被动。数值是基准值，必须试玩校准。

## 战斗模型

### 空间

- 战场是 2 条平行的水平线（Lane），每条路只有 X 轴有意义。
- 单位不能主动换路；跨路只存在于视觉排列和后续技能。
- 同路单位允许重叠，渲染时按稳定 slot 分 3 行展示；slot 不影响战斗。
- 无寻路、无物理碰撞、无地形高低差（首版）。

### 单位状态机

```text
SPAWN -> ADVANCE（前往推进线/移动目标）
           ↓ 发现敌人
        ENGAGE（停下攻击）
           ↓ 目标死亡/脱离
        ADVANCE 或 HOLD
           ↓ HP <= 0
        DEAD（本 tick 结束移除）
```

- `HOLD`：到达推进线/移动点后原地驻守，自动索敌。
- `RETURN`：按 `R` 返回本路推进线。
- 没有“逃跑”状态；玩家只能移动位置，不能强制脱战（移动中仍会攻击射程内敌人）。

### 索敌

| 规则 | 定义 |
|---|---|
| 搜索范围 | 近战 100 px；远程 = 射程 + 20 px |
| 目标选择 | 同路、范围内、最近的敌人；距离相同按 entity_id 升序（确定性） |
| 攻击条件 | 目标在射程内且自身未死亡 |
| 目标死亡 | 立即重新索敌；没有目标则回到移动/HOLD |
| 不攻击 | 不攻击建筑（首版防守关无目标建筑）；不攻击友军；无友伤 |

### 攻击与投射物

- 近战：进入 24 px 后按攻击间隔造成伤害，无弹道。
- 远程/攻城：发射投射物，追踪目标；目标死亡则投射物失效。
- 投射物速度：箭 300 px/s、魔法 250 px/s、石弹 200 px/s。
- 伤害在命中时结算，不在发射时结算。
- 攻击间隔固定，不受移动影响（除弓箭手被动）。

### 伤害结算顺序

```text
最终伤害 = 基础伤害
         x 攻型/甲型克制乘数
         x 被动乘数
         x 其他修正
最低 1 点（非 0）
```

- 无护甲减伤、无暴击、无闪避（首版）。
- 溅射只对主目标结算一次被动；溅射伤害不再触发溅射。
- 伤害取整：四舍五入到整数，保证可读。

### 死亡与奖励

- HP ≤ 0 的单位在 tick 结束时移除，播放死亡动画。
- 击杀者获得金币 = 目标成本的 20%（向下取整，最低 1）。
- 敌人抵达玩家基地：单位消失，基地扣血（普通 1、精英 2、首领 5）。
- 玩家单位抵达敌方基地：防守关敌方门不可摧毁，单位停在门前；推进关对敌方基地造成伤害。

### 基地

| 属性 | 首版 |
|---|---|
| 基地血量 | 20 |
| 被普通单位突破 | -1 |
| 被精英单位突破 | -2 |
| 被首领单位突破 | -5 |
| 基地攻击 | 无 |
| 基地可被玩家攻击 | 防守关不可；推进关 `后期` 可 |

## 攻型与甲型

| 攻型 | 代表兵种 | 特点 |
|---|---|---|
| 近战 | 剑盾兵、长矛兵、骑士 | 贴脸、怕被远程集火、破轻甲 |
| 远程 | 弓箭手、法师 | 后排持续输出、脆、通用 |
| 攻城 | 投石车 | 慢、射程远、破重甲/建筑、怕近战 |

| 甲型 | 代表兵种 | 特点 |
|---|---|---|
| 轻甲 | 长矛兵、弓箭手、法师、投石车 | 怕近战，血少 |
| 重甲 | 剑盾兵、骑士 | 抗近战，怕攻城/破甲 |

### 软克制矩阵

伤害乘数（攻击方 -> 防守方）：

| 攻型 \ 甲型 | 轻甲 | 重甲 |
|---|---:|---:|
| 近战 | **1.5x** | **0.75x** |
| 远程 | 1.0x | 1.0x |
| 攻城 | 0.5x | **1.5x** |

设计意图：

- 近战克轻甲（切后排），但砍重甲乏力。
- 远程通用，不提供极端克制，靠射程和数量。
- 攻城克重甲，但被轻甲近战克制。
- 长矛兵用被动局部改写“近战 vs 重甲”的 0.75x -> 1.25x，成为解题兵种。
- 投石车用被动强化对建筑/重甲，成为重甲杀手。

> 矩阵乘数可在试玩中调整；任何调整必须同时更新本表与 [03](03-经济与建筑.md) 的成本/人口，避免“强且便宜”。

### 兵种定位

#### 剑盾兵（前排肉盾）

- 便宜、血厚、重甲；适合堵路口、吸收远程火力。
- 被动 **盾墙**：受到远程攻击伤害 -30%。
- 弱点：被长矛兵/投石车克制；输出低，不能单靠它赢。

#### 长矛兵（反重甲）

- 近战轻甲，速度略快；用于处理剑盾兵/骑士。
- 被动 **破甲**：攻击重甲目标时，克制乘数改为 1.25x（覆盖 0.75x）。
- 弱点：脆，怕弓箭手/法师集火；对轻甲只有 1.5x 正常近战优势。

#### 弓箭手（后排持续输出）

- 远程通用，射程 170；适合躲在剑盾兵后面。
- 被动 **齐射**：连续 1.5 秒未移动且正在攻击时，攻击间隔 -20%（DPS +25%）。
- 弱点：血量最低；被近战贴脸快速死亡。

#### 法师（范围/清群）

- 远程，攻击造成小范围魔法伤害；用于处理密集轻甲群。
- 被动 **溅射**：主目标周围 50 px 内其他敌人受到 50% 最终伤害。
- 弱点：人口 2、成本高、攻速慢；单体 DPS 不如弓箭手。

#### 骑士（突进/切后排）

- 高速近战重甲；用于快速接敌、冲击远程阵型。
- 被动 **冲锋**：每个单位首次攻击伤害 x2。
- 弱点：贵、人口 2；被长矛兵/投石车克制；冲太深会脱节。

#### 投石车（攻城/破重甲）

- 超远程、慢速、高单发；用于拆重甲和后续建筑。
- 被动 **攻坚**：对建筑伤害 +50%；对重甲单位额外 +25%（与矩阵相乘）。
- 弱点：攻速慢、近战无力；被快速单位贴脸即死。

### 克制关系速查

| 你想打 | 用 | 不要用 |
|---|---|---|
| 剑盾兵/骑士（重甲） | 长矛兵、投石车 | 剑盾兵、骑士（近战 0.75x） |
| 弓箭手/法师/投石车（轻甲） | 剑盾兵、长矛兵、骑士 | 投石车（0.5x） |
| 密集轻甲群 | 法师溅射、弓箭手 | 单体近战 |
| 快速突进 | 长矛兵堵路 + 弓箭手后排 | 投石车（太慢） |

## 数值目标（TTK）

| 场景 | 目标 | 说明 |
|---|---|---|
| 同级 1v1 | 6-10 秒 | 太快看不懂，太慢节奏拖 |
| 远程 vs 无保护近战 | 3-6 秒 | 切后排要有惩罚 |
| 一波战斗 | 20-40 秒 | 给玩家观察和反应时间 |
| 波次间隔 | 20-40 秒 | 够赚金币、造建筑、调线 |
| 单关时长 | 5-8 分钟 | 5-8 波 |

如果实测 TTK 偏离目标超过 30%，优先调 HP 和成本，不要同时动 5 个变量。

## 敌军镜像

- 敌方使用同一套 6 兵种数据，只换红色调/轮廓标识。
- 不单独做敌方 AI 经济：主线按固定波次表生成，无尽按预算生成器生成。
- 敌方单位同样受人口/成本约束吗？**不**。波次表直接给定数量，预算只用于生成器。
- 敌方单位不获得击杀金币（避免滚雪球）；玩家击杀敌人获得金币。
- 敌方波次可以带精英/首领标签：HP x1.5 / x3，基地伤害 2 / 5，掉落金币 x1.5 / x3。

## 波次构成原则

1. 每波有一个“主题”：重甲、轻甲群、快速突进、远程压制、混合。
2. 每关有一个“标志性敌人”，逼迫玩家换兵种或换线。
3. 单波敌军数量 4-12；同屏总数控制在 40 以下（性能与可读性）。
4. 第 1 波弱、第 2 波教学、倒数第 2 波压力峰值、最后一波首领/混合。
5. 波次表精确到：时间、路、兵种、数量、精英标记；见 [04](04-关卡与模式.md)。

## 调参杠杆

按影响从大到小：

1. **波次预算/数量**：最直接改变难度。
2. **金币收入/起始金币**：改变玩家出兵速度。
3. **单位成本/人口**：改变组合可行性。
4. **HP**：改变 TTK 与容错。
5. **DPS/攻击间隔**：改变击杀速度，慎动。
6. **克制乘数**：改变兵种优先级，影响最大，最后动。
7. **移动速度**：改变接敌与换线节奏，容易破坏关卡脚本。

每次只动一个杠杆，记录在 [09](09-风险与决策记录.md) 的试玩记录中。

## 后续机制接口（`后期/远期`）

这些机制不进入首版，但模拟层要留出扩展点：

| 机制 | 扩展方式 | 不做的原因 |
|---|---|---|
| 埋伏 | 单位增加 `hidden` 状态与视野规则；进入埋伏区不显示，接敌/被侦察后显形 | 需要视野/侦察系统，首版 UI 与 AI 成本高 |
| 集团魔法 | 全局指令 `cast_spell`，范围效果，充能/次数限制 | 需要技能 UI、目标选择、平衡 |
| 预设阵型 | 出兵命令带 formation offset；单位按槽位落位 | 与拖拽编队部分重叠，先验证基础操控 |
| 英雄 | 特殊单位 + 玩家直接指令 + 光环/主动技能 | 阶段 3，动画与手感成本高 |
| 多路 | Lane 数组扩展；镜头/小地图适配 | 首版先把 2 路做扎实 |

## Open Questions

- 投石车是否需要最小射程（防止贴脸仍能砸）？首版暂不设，试玩后再定。
- 法师溅射是否应递减（50%/25%）？首版固定 50%，避免复杂。
- 弓箭手“齐射”站定 1.5 秒是否太苛刻？可用“未移动 1 秒”替代。
- 骑士冲锋首次攻击 x2 是否会造成开局秒杀？需要 TTK 测试。
- 是否需要“精英/首领”在首版出现？第 5 关可放 1 个精英骑士作为考试。
