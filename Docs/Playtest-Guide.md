# SimpleGame M6 试玩反馈指南

> 版本：M6 / 0.6.0 ｜ 平台：Windows x86_64 ｜ 2026-11-02
> 这是原型。目标：验证中文界面、选中/分组指挥、两路地图可读性、C3 难度与数值表。

## 运行

1. 解压 zip（不要只拿 exe）。
2. 双击 `SimpleGame.exe`。未签名，SmartScreen 可能提示，选“更多信息→仍要运行”。
3. 地图编辑器：调试版按 `F3`；发行版用 `SimpleGame.exe --map-editor` 启动。

## 先做

1. 关卡选择点委托 1。
2. 按 `B` 打开协会，点击 **铁誓会** 花 30 金建交；否则职业卡锁定。
3. 按 `Shift + 右键` 设置推进线；新兵会前进并停在该线。
4. 击杀金色菱形**悬赏目标**积累名望；名望达标后点“晋升”花金币提升声望。
5. 拖框选中多名冒险者，在右侧面板切换“协会/攻型/甲型/职业”，点分组后右键移动。

## 操作

| 输入 | 行为 |
|---|---|
| 1-8 | 当前路招募职业 |
| Alt+1-8 | 另一路招募 |
| Q/E | 切换当前路 |
| 左键/拖框 | 选单位；Shift 加选 |
| 右键 | 移动选中单位 |
| Shift+右键 | 设置推进线 |
| H / R | 驻守 / 返回推进线 |
| Ctrl+R | 重开委托 |
| B | 协会（声望/协会） |
| F1 / F2 | 战地指南（←/→翻页）/ 首局步骤 |
| F / A-D / Home | 跟随/平移/回基地 |
| Space / Esc | 暂停 / 委托列表 |
| F3（调试版） | 地图编辑器 |

小地图：左键点击切路；左键拖拽框选；右键移动；Shift+右键设推进线。

4. 两路道路宽度段是否提升可读性？有没有遮挡单位或选框？

6. C3 难度：首通/重试/基地剩余；哪一波最挫败？
7. 8 职业是否各有用途？你实际出了几个职业？
8. 640x360 的中文 HUD/选中面板/协会/预览/tooltip 是否太挤？
9. 地图编辑器（F3 或 `--map-editor`）能否完成“改宽度段 → F8 校验 → F5 保存 → 重载仍生效”？
10. 最影响体验的 1 个问题是什么？

## 已知限制

- 占位矩形美术，无音频；后续换像素/音频。
- 仍是两条直线路；交汇/多基地/多向/真图/玩家地图导入为 M7。
- 地图编辑器为调试工具：无撤销、无波次时间线、无玩家导入。
- 无第 4-5 委托、英雄上场、埋伏/魔法/阵型、联机。
- C3 已重调到自动 9/20，但真人难度仍待反馈。
- 伤害数字未做（P1）；先看 tooltip/波次预览/结算原因。
- 无存档损坏 UI 提示；测试时会恢复存档。
