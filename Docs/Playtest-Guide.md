# SimpleGame M7 试玩反馈指南

> 版本：M7 / 0.7.0 ｜ 平台：Windows x86_64 ｜ 2026-11-03
> 这是原型。目标：验证节点图多路线、相机缩放/小地图、容量/站位、暂停与存档、中文可读性、C3 难度。

## 运行

1. 解压 zip（不要只拿 exe）。
2. 双击 `SimpleGame.exe`。未签名，SmartScreen 可能提示，选“更多信息→仍要运行”。
3. 调试版按 `F3` 打开节点图编辑器；发行版用 `SimpleGame.exe --map-editor`。

## 先做

1. 关卡选择点委托 1。
2. 按 `B` 打开协会，点击 **铁誓会** 建交；否则职业卡锁定。
3. 按 `Q/E` 切换出生路线；`Shift + 右键` 在当前路线设集结点。
4. 击杀金色菱形**悬赏目标**积累**功勋**；功勋达标后点“晋级 R1”花金币提升声望。
5. 拖框选中多名冒险者，在右侧面板切换“协会/攻型/甲型/职业”，点分组后右键移动。
6. 按 `Space` 打开暂停菜单，试用“备份进度”和“站位顺序”。

## 操作

| 输入 | 行为 |
|---|---|
| 1-8 | 当前路线招募 |
| Alt+1-8 | 下一路线招募 |
| Q/E | 切换出生路线 |
| 左键/拖框 | 选单位；Shift 加选（可在道路外起框） |
| 右键 | 移动选中 |
| Shift+右键 | 设置当前路线集结点 |
| H / R | 驻守 / 返回集结点 |
| 滚轮 / - / = | 镜头缩放 |
| F / WASD / Home | 跟随/平移/回基地 |
| B | 协会 |
| Space / Esc | 暂停菜单 / 打开暂停菜单 |
| F1 / F2 | 战地指南（←/→翻页）/ 首局步骤 |
| S（关卡选择） | 存档与备份 |
| F3（调试版） | 地图编辑器 |

小地图：左键跳镜头；左键拖框选；右键移动；Shift+右键设集结点；`-`/`+` 缩放。相机框随缩放同步。

## 本次重点反馈（M7）

1. 俯视多路线/交汇是否比两路更清楚、更有决策？哪条路最容易漏看？
2. Q/E 路线 + Shift+右键集结点是否直观？新兵会不会去错路线？
3. 相机缩放（滚轮/按钮）和小地图相机框是否同步？框选/右键在缩放后是否准确？
4. 从道路外空白起框能选中单位吗？有没有 HUD 挡框/拖拽卡住？
5. 道路容量/节点排队是否看得懂？有没有莫名卡住/清不掉残敌？
6. 站位顺序默认是否合理？暂停菜单里上/下调整后，排队/前后站姿有变化吗？
7. 暂停菜单是否真正冻结游戏？F1/Space/Esc 是否还有冲突？
8. 存档面板：备份/恢复/新存档是否敢用？备份列表时间/进度是否够清楚？
9. 功勋/声望/晋级/协会门槛现在是否能解释？还觉得“晋升弱”吗？
10. C3 难度：首通/重试/基地剩余；哪一波/哪条路线最挫败？

## 已知限制

- 占位矩形美术，无音频。
- 只有单玩家/单敌方基地；多基地、玩家地图编辑/导入、2.5D 高度为 M8+。
- 调试编辑器无撤销/玩家地图库；F3 仅调试版，发行版用 `--map-editor`。
- 三协会费用仍相同；晋级数值仍只有兵力上限/协会门槛（M7 只改文案）。
- 自动试玩：C1 20/20、C2 6/20、C3 7/20、无尽 15 波；真人指标待反馈。
- 伤害数字未做（P1）。
