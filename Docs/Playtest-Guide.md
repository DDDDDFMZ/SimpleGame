# SimpleGame M5 试玩反馈指南

> 版本：M5 / 0.5.0 ｜ 平台：Windows x86_64 ｜ 2026-11-02
> 这是原型。目标：验证信息是否看得懂、战术搭配是否明显、C3 难度、CSV 数值表。

## 运行

1. 解压 zip（不要只拿 exe）。
2. 双击 `SimpleGame.exe`。未签名，SmartScreen 可能提示，选“更多信息→仍要运行”。

## 先做

1. 关卡选择点契约 1。
2. 按 `B` 打开 Company，点击 **Iron Oath** 花 30 金建交；否则职业卡锁定。
3. 按 `Shift + 右键` 把推进线压前；新兵默认守基地门口。
4. 击杀金色标记的**目标敌人**积累名望；名望达标后点 PROMOTE 花金币晋升。

## 操作

| 输入 | 行为 |
|---|---|
| 1-8 | 当前路招募职业 |
| Alt+1-8 | 另一路招募 |
| Q/E | 切换当前路 |
| 左键/拖框 | 选单位；Shift 加选 |
| 右键 | 移动选中单位 |
| Shift+右键 | 设置推进线 |
| H / R | 驻守 / 返回推进线 |
| Ctrl+R | 重开契约 |
| B | Company（声望/协会） |
| F / A-D / Home | 跟随/平移/回基地 |
| Space / Esc | 暂停 / 契约列表 |

小地图：左键点击切路；左键拖拽框选；右键移动；Shift+右键设推进线。

## 本次重点反馈（M5）

1. 首局 checklist 是否带你走完 B -> 建交 -> 招募 -> 压线 -> 目标 -> 晋升？第几步卡住？
2. 卡牌右上攻/甲缩写和 hover tooltip 是否让你看懂“这个兵打什么、怕什么”？
3. 右上 NEXT WAVE 预览是否帮你提前换兵/换线？C3 70s 骑士波是否仍突然？
4. 金目标 -> +15g +1 Fame -> PROMOTE 的链条，你是否能在 3 分钟内解释？
5. 结算原因（漏怪 Top3/花费/未花金币）是否告诉你输在哪？
6. F1 Field Guide 是否好用？哪个词仍不懂？
7. C3 难度：首通/重试/基地剩余；哪一波最挫败？
8. 8 职业是否各有用途？你实际出了几个职业？
9. 640x360 的 8 卡/Company/预览/tooltip 是否太挤？
10. 最影响体验的 1 个问题是什么？

## 已知限制

- 占位矩形美术，无音频；后续换像素/音频。
- 战斗 HUD 英文；关卡选择/简报中文。
- 无第 4-5 契约、英雄上场、埋伏/魔法/阵型、联机。
- 选中单位信息/分类、地图编辑器、多基地/交汇/多向地图为 M6/M7。
- C3 已重调到自动 9/20，但真人难度仍待反馈。
- 伤害数字未做（P1）；先看 tooltip/波次预览/结算原因。
- 无存档损坏 UI 提示；测试时会恢复存档。
