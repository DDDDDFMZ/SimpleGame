# SimpleGame M4 试玩反馈指南

> 版本：M4 / 0.4.0 ｜ 平台：Windows x86_64 ｜ 2026-11-02
> 这是原型。目标：验证冒险者公会经济、8 职业、镜头/小地图、3 契约+无尽。

## 运行

1. 解压 zip（不要只拿 exe）。
2. 双击 `SimpleGame.exe`。未签名，SmartScreen 可能提示，选“更多信息→仍要运行”。

## 先做

1. 关卡选择点契约 1。
2. 按 `B` 打开 Company，点击 **Iron Oath** 花 30 金建交；否则职业卡锁定。
3. 按 `Shift + 右键` 把推进线压前；新兵默认守基地门口。
4. 击杀金色标记的**目标敌人**积累名望；名望达标后点 PROMOTE 花金币晋升。

## 操作

| 输入 | 行为 |
|---|---|
| 1-8 | 当前路招募职业 |
| Alt+1-8 | 另一路招募 |
| Q/E | 切换当前路 |
| 左键/拖框 | 选单位；Shift 加选 |
| 右键 | 移动选中单位 |
| Shift+右键 | 设置推进线 |
| H / R | 驻守 / 返回推进线 |
| Ctrl+R | 重开契约 |
| B | Company（声望/协会） |
| F / A-D / Home | 跟随/平移/回基地 |
| Space / Esc | 暂停 / 契约列表 |

小地图：左键点击切路；左键拖拽框选；右键移动；Shift+右键设推进线。

## 本次重点反馈

1. `B` 建交/升级协会是否看得懂？第一次建交用了多久？
2. 8 职业是否各有用途？你有没有固定只出某几个？
3. 声望“目标击杀+金币宣传”双条件是否成立？会不会太烦？
4. 协会合作每局重置是否合理？局外人情有没有长期动力？
5. 镜头/小地图/推进线/框选是否顺手？
6. 战斗优先移动、单位不再抖动，是否明显改善？
7. C1/C2/C3 难度分别如何？C3 是否过难？
8. 无尽 10 波是否可达？分数/节奏如何？
9. 640x360 的 8 卡/Company 面板/中文关卡选择是否可读？
10. 最影响体验的 1 个问题是什么？

## 已知限制

- 占位矩形美术，无音频；M5 换像素/音频。
- 战斗 HUD 英文；关卡选择/简报中文。
- 无第 4-5 契约、英雄上场、埋伏/魔法/阵型、联机。
- 协会人情/难度为初调，C3 当前上限。
- 无存档损坏 UI 提示；测试时会恢复存档。
