# SimpleGame M7.2 试玩/验证指南

> 版本：M7.2 / 0.7.2 源码（本阶段不打包） ｜ 平台：Windows x86_64 ｜ 2026-11-05
> 这是原型。目标：验证 120% 索敌、受击支援、队列/横向阵线、移动优先，以及既有 JSON/设置/节点图/相机/存档/暂停/中文可读性。

## 运行

1. 用 Godot 4.7 打开项目 `project.godot`，F5 运行；或使用 `--path .` 启动。
2. 本阶段**没有新 zip/Release**；如需试玩包，使用上一版 M7 包并在源码中验证 M7.2 改动。
3. 调试版按 `F3` 打开节点图编辑器；任意版本可用 `--map-editor`。

## 先做

1. 关卡选择点委托 1。
2. 按 `B` 打开协会，点击 **铁誓会** 建交；否则职业卡锁定。
3. 按 `Q/E` 切换出生路线；`Shift + 右键` 在当前路线设集结点。
4. 击杀金色菱形**悬赏目标**积累**功勋**；功勋达标后点“晋级 R1”花金币提升声望。
5. 拖框选中多名不同速度冒险者右键移动，观察队首/间距/等待；到达后是否展开成战线；再按 `H/R` 解散编队。
6. 按 `Space` 打开暂停菜单，进入“设置”改默认缩放/站位；再按 `O`（关卡选择）试用同一面板。
7. 按 `S` 在关卡选择备份/恢复/新存档，确认设置不被覆盖。

## 操作

| 输入 | 行为 |
|---|---|
| 1-8 | 当前路线招募 |
| Alt+1-8 | 下一路线招募 |
| Q/E | 切换出生路线 |
| 左键/拖框 | 选单位；Shift 加选（可在道路外起框） |
| 右键 | 移动选中 |
| Shift+右键 | 设置当前路线集结点 |
| H / R | 驻守 / 返回集结点 |
| 滚轮 / - / = | 镜头缩放 |
| F / WASD / Home | 跟随/平移/回基地 |
| B | 协会 |
| Space / Esc | 暂停菜单 / 打开暂停菜单 |
| O（关卡选择/暂停） | 设置：默认缩放、窗口缩放/全屏、站位顺序 |
| F1 / F2 | 战地指南（←/→翻页）/ 首局步骤 |
| S（关卡选择） | 存档与备份 |
| F3（调试版） | 地图编辑器 |

小地图：左键跳镜头；左键拖框选；右键移动；Shift+右键设集结点；`-`/`+` 缩放。相机框随缩放同步。

## 本次重点反馈（M7.2）

1. 单位是否只在自己射程附近接敌？有没有远距离拉怪、追到地图尽头或站桩不打？
2. 前排被攻击时，附近远程是否开火？有没有全队跨图追一个攻击者？
3. 队列是否还会卡住？队首/队尾顺序、位置方向是否清楚？
4. 单位默认是否在中线？多单位并排/部署点已占用/避让时是否平滑横向展开并成战线？
5. 右键移动能否把单位从战斗中拉走调整位置？途中是否仍攻击射程内目标？到达后是否恢复自动战斗？
6. 框选混合速度单位移动时，队首/间距/等待/反向是否自然？有没有超车、抖动或卡住？
7. 设置/存档/地图编辑器/相机缩放等既有功能是否仍正常？
8. 功勋/声望/晋级/协会门槛是否能解释？C1-C3/无尽难度是否可接受？

## 已知限制

- 本阶段不打包/不发 Release；只提供源码 0.7.2 与测试结果。
- 占位矩形美术，无音频。
- 只有单玩家/单敌方基地；多基地、玩家地图编辑/导入、2.5D 高度为 M8+。
- 调试编辑器无撤销/玩家地图库；F3 仅调试版，发行版用 `--map-editor`。
- 三协会费用仍相同；晋级数值仍只有兵力上限/协会门槛（M7.2 未改数值）。
- 编队只做“同路线统一最低速度 + 队长轨迹跟随”，不做逐单位分散寻路模式。
- 自动试玩（M7.2）：C1 20/20、C2 6/20、C3 11/20、无尽 18 波（第 18 波失守）；真人指标待反馈。
- 伤害数字未做（P1）。
