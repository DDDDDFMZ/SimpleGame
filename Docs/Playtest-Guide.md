# SimpleGame M3 试玩反馈指南

> 版本：M3（0.3.0）｜ 平台：Windows x86_64 ｜ 构建日期：2026-10-29
> 这是原型，不是完成品。目标是用最小成本验证：镜头/小地图、推进线/框选、三关难度。

## 运行

1. 解压 zip 到任意目录（不要只解压 exe）。
2. 双击 `SimpleGame.exe`。
3. 窗口 1280x720；exe 未签名，SmartScreen 可能提示“未知发布者”，选“更多信息 -> 仍要运行”。如果杀毒软件误报，请先检查文件来源或改用源码运行。

## 操作

| 输入 | 行为 |
|---|---|
| 左键点击/拖框 | 选择己方单位；`Shift` 加选 |
| 右键地面 | 选中单位移动到该位置 |
| `Shift + 右键` | 设置当前路推进线（新兵会前往并驻守） |
| `H` | 选中单位原地驻守 |
| `R` | 选中单位返回推进线 |
| `Ctrl + R` | 重开当前关 |
| `1-6` | 当前路出兵（剑盾/长矛/弓/法/骑/投石） |
| `Alt + 1-6` | 另一条路出兵 |
| `Q` / `E` | 切换当前路并跟随镜头 |
| 点击小地图 | 切路并跳到点击位置 |
| `F` | 开关镜头跟随 |
| `A` / `D` | 平移镜头（关闭跟随） |
| `Home` | 镜头回基地 |
| `B` 或点击 BUILD | 建筑面板 |
| `N` | 下一关 |
| `Space` | 暂停 |
| `Esc` | 退出 |

**先做这件事**：`Shift + 右键` 把推进线压前。新兵默认在基地门口驻守；不压线，敌方远程会在你射程外停住。

## 本次重点反馈

请按 1-5 打分（1=很差，5=很好），并写一句原因：

1. 镜头跟随是否舒服？会不会晕/找不到自己的兵？
2. 小地图是否有用？你看得懂两路谁快崩吗？
3. 框选 + 右键移动是否顺手？和“自动战斗”的预期冲突吗？
4. 推进线概念是否理解？第一次知道要压线用了多久？
5. 三关难度分别如何？哪一波/哪一关最挫败？
6. 6 个兵种是否都有用？你有没有固定只出某几个兵？
7. 金币/农场/兵营的取舍是否成立？你有没有“钱没处花”或“永远缺钱”？
8. 视觉可读性：单位、血条、波次、小地图是否看得清？
9. 你还想不想再开一局？为什么？
10. 最影响体验的 1 个问题是什么？

## M3 已知限制

- 没有关卡选择、存档、局外解锁；按 `N` 循环三关。
- 三关暂时解锁全部 6 兵种和两种建筑；正式解锁在 M4。
- 教学降维未做；先看本指南。
- 占位矩形美术，无音频；不是最终表现。
- 难度为初调；第 3 关约剩 3/20 基地，属于当前上限。
- HUD 英文、操作提示较小；M5 再打磨。
- 联机/英雄/埋伏/魔法/阵型均未实现。

## 反馈方式

- 直接回复：文字 + 截图即可。
- 有崩溃：附上 `%APPDATA%\Godot\app_userdata\SimpleGame\logs\` 下日志。
- 优先记录“第一次卡住/第一次想关游戏”的瞬间，比总体评价更有用。
