> TL;DR：Godot 4.7 + GDScript；固定 20Hz 纯逻辑层；M5 GameData/CSV；M6 两路地图；M7 节点图/2D 移动/相机缩放/容量/存档 v3/暂停模态。多基地/玩家地图编辑器/2.5D 留后续。

## 分层

```text
View（Godot 节点）: HUD/2D 地图/单位/相机/关卡选择/编辑器
   ↑ snapshot
BattleSim（RefCounted）: 图移动/战斗/波次/经济/声望/协会/容量
   ↑ command
Input/UI: 键鼠 -> queue_* -> 下一 tick 应用
```

硬规则：

- 模拟层不 `get_node`、不访问 SceneTree、不用全局随机。
- 表现层不改 HP/金币/位置；全部通过命令。
- 每 tick 产出快照；视图按 entity_id 同步；地图快照缓存。

## 地图数据（M7）

- `data/maps/*.json` v2：world、nodes（base/junction/waypoint）、edges（width/points）、spawns（team/base/entry/name）。
- 单玩家基地 + 单敌方基地；spawns 省略时自动从基地相邻边生成。
- `MapData` 校验唯一 id/端点/单基地/连通/出生口/宽度；`MapGraph` 运行时寻路。
- v1 两路 JSON 编译为图，旧自定义地图可过渡。
- 详细 schema/编辑器：[12](12-地图格式与编辑器.md)。

## 模拟层

- 单位：`pos/edge_id/edge_s/edge_dir/path/path_index/route_id/station_rank/goal`。
- 目标：同边无视 aggro；跨边在 aggro/射程内；同边追击，跨边不追。
- 战斗/治疗/溅射/投射物全部 2D 距离。
- 容量：每边每方 `width/12`；满员节点排队；容量空出按 `station_rank` 进入。
- 集结点：每路线一个投影点；新兵/无手动指令单位前往；站位顺序产生前后 offset。
- 所有波次出完，未手动驻守的单位主动清残敌。
- 快照：units pos/edge/route/waiting、routes 容量/路径/rally、map 缓存、cooldowns 按 route。

## 相机/HUD

- CameraRig：Vector2 + zoom 0.5–1.5（默认 0.8），WASD 平移，F 跟随，Home 回基地。
- 小地图：等比世界→矩形，相机框随 zoom；世界点/矩形手势。
- HUD 接收 camera_pos/zoom；框选阈值按 zoom 换算。
- 暂停：Battle 单一 `pause_mode`（NONE/MENU/GUIDE/RESULT），HUD 模态；不使用 get_tree.paused。
- 存档：v3；`SaveService` 回读校验→旧档备份→替换；损坏隔离/回退；测试注入路径。

## 输入

- 数字 1-8；Alt 下一路线；Q/E 路线；B 协会；Space/Esc 暂停/关闭；F1/F2；滚轮/-/= 缩放；WASD/F/Home 相机。
- 关卡选择 S 存档；调试版 F3 地图编辑器；发行版 `--map-editor`。

## 性能/确定性

- 20Hz；<100 单位；简单 Dijkstra 缓存；地图快照只构建一次。
- 浮点确定性未承诺；联机需主机权威/定点。
