# 06 技术架构（M4）

> 状态：`首版` ｜ 关联：[02-兵种](02-战斗与兵种.md)、[03-经济](03-经济与建筑.md)、[04-关卡](04-关卡与模式.md)
> TL;DR：Godot 4.7 + GDScript；固定 20Hz 纯逻辑层 + 表现层；M4 增加 CompanyState（金币/声望/协会/人情）、GameState/SaveService autoload、关卡选择、无尽、存档 v2。M5 增加 `GameData`（CSV 数值表）、`campaign.json`、HUD 信息层/checklist/Field Guide。

## 分层

```text
View（Godot 节点）: HUD/地图/单位/镜头/关卡选择
   ↑ snapshot
BattleSim（RefCounted）: 战斗/波次/金币/声望/协会/目标/无尽
   ↑ command
Input/UI: 键鼠 -> queue_* -> 下一 tick 应用
```

硬规则：

- 模拟层不 `get_node`、不访问 SceneTree、不用全局随机。
- 表现层不改 HP/金币/位置；全部通过命令。
- 每 tick 产出快照；视图按 entity_id 同步。

## 数据

- `data/balance/units.csv`：8 职业全部数值 + guild/tier/role/heal/backstab。
- `data/balance/guilds.csv` + `guild_tiers.csv`：3 协会/T0-T3 费用/cap/rank_gate。
- `data/balance/balance.csv` / `counters.csv`：全局经济/声望/人情/无尽/克制。
- `data/campaign.json`：契约路径/协会解锁/无尽路径。
- `data/levels/level_01..03.json` + `endless.json`：contract/brief/available_guilds/target/waves。
- `sim/game_data.gd` 是唯一 loader/validator；旧 `units.json`/`guilds.json` 已停用。
- 校验：缺字段/未知 unit/guild/lane/波次时间乱序报错；`tools/validate_data.gd` 导出前跑。
- 无持久金币；局外只存 v2 存档字段。

## 经济/协会实现

- `BattleSim` 持有 `guild_tier`（-1 未建交，0-3）、`guild_usage`、`guild_favor`（来自 GameState profile）。
- `queue_guild_action`、`queue_promote` 进命令队列；下一 tick 校验金币/名望/Rank gate。
- `_effective_def` 生成 favor 加成副本（HP/伤害/成本），不修改共享 UnitDef。
- `get_snapshot` 输出 catalog/guilds/fame/rank/cooldowns/advance_lines/guild_usage/score。
- `GameState.record_result` 写星级/契约/协会解锁/人情；人情只在星级刷新时结算，防刷。

## 移动/战斗修复

- `_move_unit` 使用 `move_toward` 语义，距离 ≤ max(1, speed*dt) 时吸附。
- 目标锁定 + aggro×1.3 滞回；丢失后 0.35s 恢复移动。
- 战斗优先于移动/推进线；`hold_position` 是不追击的例外。
- 到达敌方基地门前设置 `at_base/hold_position`，不回退。
- 世界锚点框选：HUD 按下发屏幕坐标，Battle 立即转世界；View 画世界矩形。
- 小地图手势：HUD 独立 `minimap_*` 状态；拖选/右键移动/Shift+右键推进。

## 存档 v2

- 路径 `user://save.json`；临时文件 + rename；版本 2；v1 合并默认。
- 字段见 [04](04-关卡与模式.md)；无跨关金币。
- 损坏：返回空/默认，不自动覆盖? 当前实现会在下一次保存覆盖；M5 加显式提示。

## 输入

- HUD Control 全屏 STOP，处理鼠标；Battle `_unhandled_input` 处理键盘。
- 小地图/世界/Company/卡片由 HUD 分发；世界右键转发给 Battle。
- 数字键 1-8；Alt 另一路；Q/E 切路；B Company；Ctrl+R 重试；Space 暂停；Esc 契约列表。

- 种子 RNG（无尽波次）；战斗迭代按 id；无物理/寻路。
- 浮点确定性未承诺；未来联机用主机权威或定点。
