## 分层

```text
View（Godot 节点）: HUD/2D 地图/单位/相机/关卡选择/编辑器
   ↑ snapshot
BattleSim（RefCounted）: 图移动/战斗/波次/经济/声望/协会/容量
   ↑ command
Input/UI: 键鼠 -> queue_* -> 下一 tick 应用
```

硬规则：

- 模拟层不 `get_node`、不访问 SceneTree、不用全局随机。
- 表现层不改 HP/金币/位置；全部通过命令。
- 每 tick 产出快照；视图按 entity_id 同步；地图快照缓存。

## 地图数据（M7.2）

- `data/maps/*.json` v2：world、nodes（base/junction/waypoint）、edges（width/points）、spawns（team/base/entry/name）。
- 单玩家基地 + 单敌方基地；spawns 省略时自动从基地相邻边生成。
- `MapData` 校验唯一 id/端点/单基地/连通/出生口/宽度；`MapGraph` 运行时寻路。
- v1 两路 JSON 编译为图，旧自定义地图可过渡。
- 详细 schema/编辑器：[12](12-地图格式与编辑器.md)。

## 模拟层

- 单位：`pos/edge_id/edge_s/edge_dir/path/path_index/route_id/station_rank/goal`。
- 目标：所有获取都受 `attack_range × target_range_mult`（1.2）限制；同边可在 120% 内接近，跨边只有射程内可攻击，不再无限同边追击。
- 视野簇：每 tick 按 `assist_radius` 做同队传递性连通分量；簇内共享 2.5 秒内攻击者，簇最大 120% 射程用于告警；共享不改变目标移动/路线，开火仍受自身射程限制。
- 战斗/治疗/溅射/投射物全部 2D 距离。
- 容量：每边按 `(width-2*padding)/slot_width` 的碰撞槽位，双方共享；满员节点排队；按 squad_rank/station_rank 排序进入；友方阻塞立即改路，其他阻塞 `queue_timeout` 后尝试绕行；陈旧队列自愈。
- 横向：槽位只负责容量；`_update_lateral_positions` 按同边纵向距离分组，默认中线，重叠时按队伍/横宽平滑展开。
- 移动优先：`move_priority` 由右键小队命令设置；期间跳过接敌停步，沿路径移动并攻击射程内目标；队长到达后全队统一最终点成线并清除。`_plan_from_edge` 在跨边目标时按当前边两端路程选择近端掉头。
- 编队：`queue_move_squad` 先解散旧 squad/清队列，再按 `route_id` 分组；每组取距目标最近者为队长，记录 `speed_cap=min(speed)`、目标、轨迹 trail。后排目标 = 队长轨迹后方 `rank*squad_spacing`；队长死亡提升下一 rank 并重置轨迹；队长落后队尾过远时短暂等待，但队友排队/战斗时不硬等。
- 战斗支援：`last_attacker_id/last_hit_time`；近战优先反击攻击者；附近友军的目标/攻击者通过 `assist_radius` 进入远程支援候选，只生成攻击目标，不做无限跨图追击。
- 集结点：每路线一个投影点；新兵/无手动指令单位前往；站位顺序产生前后 offset。
- 所有波次出完，未手动驻守的单位主动清残敌。
- 快照：units pos/edge/route/waiting/squad、routes 容量/路径/rally、squads 轨迹摘要、map 缓存、cooldowns 按 route。

## 相机/HUD

- CameraRig：Vector2 + zoom 0.5–1.5（默认 0.8），WASD 平移，F 跟随，Home 回基地。
- 小地图：等比世界→矩形，相机框随 zoom；世界点/矩形手势。
- HUD 接收 camera_pos/zoom；框选阈值按 zoom 换算。
- 暂停：Battle 单一 `pause_mode`（NONE/MENU/GUIDE/RESULT），HUD 模态；不使用 get_tree.paused。
- 设置：`user://settings.json`，独立于进度；旧 `save.settings` 首次迁移。
- 存档：v4；`SaveService` 回读校验→旧档备份→替换；损坏隔离/回退；测试注入路径。

## 输入

- 数字 1-8；Alt 下一路线；Q/E 路线；B 协会；Space/Esc 暂停/关闭；F1/F2；滚轮/-/= 缩放；WASD/F/Home 相机；O 设置。
- 关卡选择 S 存档、O 设置；调试版 F3 地图编辑器；发行版 `--map-editor`。

## 性能/确定性

- 20Hz；<100 单位；简单 Dijkstra 缓存；地图快照只构建一次。
- 浮点确定性未承诺；联机需主机权威/定点。
