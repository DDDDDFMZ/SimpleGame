# 01 核心循环（M4）

> 状态：`首版` ｜ 关联：[02-兵种](02-战斗与兵种.md)、[03-经济](03-经济与建筑.md)、[05-UI](05-美术音频UI.md)
> TL;DR：观察 -> 金币/声望/协会决策 -> 出兵/推线 -> 自动战斗 -> 目标击杀 -> 晋升/建交 -> 下一波。玩家是团长，不上场。

## 局内循环

```text
观察（两路/小地图/目标/波次）
  -> 金币决策（兵/声望/协会）
  -> 军事决策（哪路、职业、推进线）
  -> 自动战斗
  -> 目标击杀 + 赏金 + 波次报酬
  -> 晋升声望 / 协会升级
  -> 下一波
```

每 10 秒应至少有一个判断：

1. 现在补兵，还是攒钱升协会/声望？
2. 哪路要崩？切哪条路/压哪条推进线？
3. 目标敌人露头了吗？有没有兵能切到它？
4. 当前职业组合打得动这波甲型吗？

## 局外循环

```text
关卡选择 -> 契约 -> 结算（星级/目标/协会使用）
   ↑                         ↓
   └── 契约解锁/协会解锁/人情 ←┘
                 ↓
            无尽悬赏
```

- 关内金币/声望/协会合作每局重置。
- 局外保存：契约解锁、星级、协会解锁、人情、无尽最高分。
- 失败无损；重试重置本局，不重置局外。

## 操作

| 输入 | 行为 |
|---|---|
| 1-8 | 当前路招募对应职业 |
| Alt+1-8 | 另一路招募 |
| Q/E | 切路并跟随 |
| 左键/拖框 | 选单位；Shift 加选 |
| 右键地面 | 移动选中单位 |
| Shift+右键 | 设置当前路推进线 |
| H / R | 驻守 / 返回推进线 |
| Ctrl+R | 重开当前契约 |
| B | Company 面板 |
| F1 / F2 | Field Guide / 首局 checklist |
| Hover 卡牌 | 查看角色/攻甲/被动/克制 |
| 右上 NEXT WAVE | 下一波 lane/单位/护甲/目标 |
| F / A-D / Home | 跟随/平移/回基地 |
| Space / Esc | 暂停 / 返回关卡选择 |

## 单局节奏

| 时间 | 内容 |
|---|---|
| 0:00-0:30 | 读契约；B 建交；出基础兵；设推进线 |
| 0:30-3:00 | 第 2-4 波；第一次声望晋升；协会 T1 |
| 3:00-5:00 | 目标击杀；T2 职业；两路压力峰值 |
| 5:00-7:00 | 最后一波；结算星级 |

## 推进线与战斗

- 新兵从基地门口生成，走到本路推进线后驻守；默认门口。
- 玩家必须用 `Shift+右键` 压线，否则敌方远程会停在射程外。
- 单位接敌后战斗优先于移动；清敌后恢复移动点/推进线。
- 到达目标点会吸附，不再来回抖动。

## 三阶段演进

| 阶段 | 操作 | 版本 |
|---|---|---|
| P1 自动战斗 | 金币/声望/协会、出兵、推进线、拖拽小队 | M4 |
| P2 轻微微操 | 攻击移动、集火、单位技能 | M5+ |
| P3 英雄带队 | 凯尔上场、光环/主动技能/死亡规则 | M5-M6（仅团长叙事至 M4） |
