# 01 核心循环

> 状态：`首版` ｜ 关联：[02-战斗与兵种](02-战斗与兵种.md)、[03-经济与建筑](03-经济与建筑.md)、[04-关卡与模式](04-关卡与模式.md)
> TL;DR：观察 -> 赚钱/造建筑 -> 推线/出兵 -> 自动战斗 -> 结算 -> 下一波。玩家只做三类决策：钱花在哪、兵放哪路、推进线压到哪。

## 局内循环

```text
┌─────────────────────────────────────────────────────┐
│  1. 观察                                           │
│     看小地图/波次计时/两路兵力对比                   │
│        ↓                                           │
│  2. 资源决策                                       │
│     金币：造农场/兵营？还是留着出兵？                │
│        ↓                                           │
│  3. 军事决策                                       │
│     哪路补兵？兵种克制对不对？推进线前压还是后撤？   │
│        ↓                                           │
│  4. 自动战斗                                       │
│     单位自动索敌、攻击、死亡；玩家可拖拽小队改位置   │
│        ↓                                           │
│  5. 反馈                                           │
│     击杀得金币、基地掉血、波次推进、建筑可升级       │
│        ↓                                           │
│  6. 下一波（回到 1）                                │
└─────────────────────────────────────────────────────┘
```

### 玩家每 10 秒应该做的判断

1. 现在的金币够不够出兵？还是再等 2 秒买更贵的兵？
2. 两条路哪边压力大？我要不要切过去？
3. 推进线是压前吃击杀，还是缩回基地保血量？
4. 这波敌人是什么甲/什么攻型？我现有的兵够不够用？

如果 10 秒内没有以上任何一个判断，说明关卡节奏太松或 UI 信息不足。

## 局外循环

```text
关卡选择 -> 选关/看目标 -> 局内 -> 结算（1-3 星）
   ↑                                  ↓
   └── 解锁下一关 / 新兵种 / 新建筑 ←──┘
                  ↓
            无尽模式（通关第 3 关后解锁）
```

- 失败无损：立刻重试，不扣资源、不耗体力。
- 首版局外只做“通关解锁”；星级记录但不可消费（`后期` 再做星级升级与遗物）。
- 关卡选择显示：目标、最佳星级、是否解锁。

## 三阶段演进

| 阶段 | 玩家操作 | 自动程度 | 版本 | 架构要求 |
|---|---|---|---|---|
| P1 自动战斗 | 出兵、建筑、推进线、拖拽小队 | 单位自动索敌/攻击/推进 | `首版` | 命令层 + 固定 tick 模拟 |
| P2 轻微微操 | 增加攻击移动、集火、驻守、单位主动技能 | 仍自动，但可下达战术指令 | `后期` | 命令队列支持新指令类型 |
| P3 英雄带队 | 玩家操控英雄，光环/大招，英雄死亡惩罚 | 小兵自动，英雄手动 | `远期` | 输入层与模拟层解耦；英雄作为特殊实体 |

P1 的“拖拽小队”是基础操控，不是 P2 的微操：只能移动位置/改变驻守点，不能指定攻击目标或释放技能。

## 单局结构

| 时间 | 内容 | 玩家体验 |
|---|---|---|
| 0:00-0:20 | 关卡目标、波次预览、初始金币 | 看懂这关要干什么 |
| 0:20-1:00 | 第一波；造第一个农场或兵营 | 第一个经济决策 |
| 1:00-3:00 | 第 2-4 波；两路开始同时施压 | 第一次换线救火 |
| 3:00-6:00 | 第 5-7 波；标志性敌人出现 | 用兵种克制解题 |
| 6:00-8:00 | 最后一波；基地血量告急或稳住 | 结算前的紧张 |
| 结算 | 星级、击杀、金币、重试/下一关 | 知道输赢原因 |

首版单关 **5-8 分钟，5-8 波**；教学关 4 分钟 / 4 波。

## 操作映射（首版）

### 鼠标

| 输入 | 行为 |
|---|---|
| 左键点击单位 | 选中该单位/小队 |
| 左键拖框 | 框选己方单位 |
| `Ctrl + 左键` | 加选/减选 |
| 右键地面 | 选中部队移动到该点并驻守；移动途中自动攻击射程内敌人 |
| `Shift + 右键` | 设置**当前路推进线**（新兵出生后前往该线并驻守） |
| 右键敌方单位 | 不指定目标（首版不做集火）；仅移动 |
| 点击小地图 | 镜头跳到该路对应位置 |
| 点击建筑槽位 | 打开建造/升级菜单 |

### 键盘

| 按键 | 行为 | 备注 |
|---|---|---|
| `1-6` | 在当前镜头所在路出兵 | 对应 6 兵种 |
| `Alt + 1-6` | 在另一条路出兵 | 快速双线补兵 |
| `Q` / `E` | 镜头切到上路 / 下路 | 也用于小地图选择 |
| `Tab` | 循环切换路 | 单手可用 |
| `WASD` / 中键拖拽 | 平移镜头 | 跟随模式下仍可临时平移 |
| `F` | 跟随/取消跟随选中部队 | 默认不跟随，防止镜头被拖走 |
| `Home` | 镜头回基地 | |
| `Space` | 暂停/继续 | 暂停时可下令 |
| `H` | 选中部队原地驻守（取消移动） | |
| `R` | 选中部队返回本路推进线 | |
| `B` | 打开/关闭建筑面板 | |
| `Esc` | 暂停菜单 | |

首版不做编队号码（`Ctrl+1` 编队），避免与出兵键冲突；拖拽框选足够。

### 镜头规则

- 横版侧视，镜头只沿 X 轴平移；两条路垂直排列，切换路时镜头纵向跳转并短暂缓动。
- 默认镜头停在当前路的中段；战斗发生在哪，玩家自己切。
- 镜头不强制跟随战斗，避免玩家失去对另一条路的控制感。
- 小地图始终显示两路全局，是“另一条路发生了什么”的主要信息来源。

### 小地图规则

```text
┌──────────────────────────────┐
│ 上路  ███████░░░░  基地 18/20 │
│ 下路  ████░░░░░░░  基地 18/20 │
│ 波次 3/7  下一波 00:12        │
└──────────────────────────────┘
```

- 两条水平条代表两路；蓝色=己方，红色=敌方，图标大小表示兵力规模。
- 显示：双方基地血量、推进线位置、当前波次/下一波倒计时、英雄/首领图标（后期）。
- 首版不显示敌方具体兵种（情报系统 `后期`）；只显示“有敌军/数量级”。
- 点击条带切路；`Q/E` 同步高亮。

## 出兵规则

1. 单位从己方基地门口生成，不能直接在战场中央召唤。
2. 出兵消耗金币 + 占用人口；人口满时按钮变红，必须先有单位死亡或升级兵营。
3. 每个兵种独立冷却（2-5 秒），不是全局冷却；冷却期间按钮显示灰条。
4. 新兵出生后沿本路前往**推进线**；到达后驻守，自动攻击进入射程的敌人。
5. 推进线默认在基地门口；玩家可用 `Shift + 右键` 前移/后移。推进线只影响新兵与 `R` 返回的部队，不影响已选中并移动的部队。
6. 已存在的部队可框选后右键移动到任意己方可达地面；到达后驻守。没有“自动继续推进”，除非玩家按 `R` 返回推进线或重设推进线。
7. 单位不能主动换路（首版）；换线只能靠在新路出兵。

### 为什么用“推进线”而不是全自动冲锋

全自动冲锋会让玩家的位置决策退化为“点兵”，两条线的差别只剩数值。推进线把“压多深”变成可操作的风险决策：

- 压前：更早接敌、吃击杀奖励，但后排暴露、基地空虚。
- 缩回：安全，但放敌人接近基地，容错变低。
- 两路推进线不一致时，玩家必须判断先救哪边。

## 拖拽编队（首版）

- 框选最多 12 个单位；选中后显示地面圆环。
- 右键移动：整队以松散队形前往目标点（沿路 X 轴，不跨路）。
- 移动途中自动攻击射程内敌人，不停止前进（除非接敌进入近战）。
- `H` 驻守：停止移动并原地索敌。
- `R` 返回推进线：整队走回本路推进线并驻守。
- 拖拽不会改变兵种 AI、不会指定目标；这是位置控制，不是微操。
- 选中跨路单位时，右键目标点按各自路分别处理；不做跨路移动。

## 胜负与结算

### 防守关（首版唯一目标类型）

- 基地血量 20。敌人抵达基地即消失并扣血：普通 1、精英 2、首领 5。
- 守住全部波次且基地血量 > 0 = 胜利。
- 基地血量归零 = 失败，立即弹出重试。
- 星级：
  - 1★：通关。
  - 2★：基地血量 ≥ 12。
  - 3★：基地血量 ≥ 18。
- 失败无损；重试保留关卡解锁与已记录的最高星级。

### 后续目标类型（`后期`）

| 目标 | 规则 | 版本 |
|---|---|---|
| 推进 | 拆毁敌方基地；玩家单位抵达敌方基地造成伤害 | v0.2 |
| 护送 | 保护车队从己方基地到终点；车队被毁失败 | v0.2 |
| 限时坚守 | 在时间结束前守住指定区域/基地 | v0.2 |
| 混合 | 一关内分阶段切换目标 | v0.3 |

## 教学关设计（第 1 关内置）

参考 PvZ 1-1 的降维思路，不另做教学关：

| 步骤 | 解锁内容 | 限制 |
|---|---|---|
| 开局 | 只有上路、只有剑盾兵、金币 150 | 下路被雾气遮住，不可操作 |
| 第 1 波 | 剑盾兵 vs 剑盾兵 | 教会“出兵 -> 自动战斗” |
| 第 2 波后 | 解锁弓箭手 | 教会远程后排 |
| 第 3 波后 | 解锁下路、农场 | 教会双线与经济 |
| 第 4 波 | 两路同时来敌 | 教会换线与推进线 |
| 结算 | 提示“可以重试刷 3 星” | 建立重玩预期 |

教学提示用屏幕上方 1-2 行文字 + 高亮按钮，不做强制点击弹窗；玩家可跳过。

## 暂停与重试

- `Space` 暂停，暂停时可看出兵栏、建筑面板、小地图，可下令；恢复后执行。
- 首版不做时间加速；`后期` 加 1x/2x 切换。
- 重试从第 1 波开始，金币/建筑/人口重置；已解锁内容不变。
- 关卡中途退出保留已解锁进度，不保留局内状态。

## Open Questions

- 推进线是否需要“前压自动接敌”开关，还是完全靠玩家右键移动？（试玩验证）
- 拖拽编队上限 12 是否合适？两路各 10 人口时可能不够。
- 小地图是否显示敌方兵种轮廓？首版偏“只显示数量”，避免信息过载。
- 失败结算是否显示“输在哪”统计（漏怪类型/经济曲线）？首版可只显示基地血量与波次。
