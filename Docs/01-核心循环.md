# 01 核心循环（M7.1）

> 状态：`首版` ｜ 关联：[02-兵种](02-战斗与兵种.md)、[03-经济](03-经济与建筑.md)、[05-UI](05-美术音频UI.md)、[12-地图](12-地图格式与编辑器.md)
> TL;DR：观察多路线/交汇 -> 金币/功勋/协会决策 -> 选出生路线、设集结点、出兵 -> 图寻路自动战斗 -> 悬赏击杀 -> 晋级/建交 -> 下一波。玩家是团长，不上场。

## 局内循环

```text
观察（多路线/交汇/小地图/目标/波次）
  -> 金币决策（兵/声望/协会）
  -> 军事决策（出生路线、职业、集结点、容量）
  -> 图寻路 + 2D 自动战斗
  -> 目标击杀 + 赏金 + 波次报酬
  -> 晋级声望 / 协会升级
  -> 下一波
```

每 10 秒应至少有一个判断：

1. 现在补兵，还是攒钱升协会/声望？
2. 哪条路线/交汇要崩？Q/E 换路线，Shift+右键改集结点。
3. 目标敌人露头了吗？有没有兵能跨交汇切到它？
4. 当前职业组合打得动这波甲型吗？道路容量会不会堵住？

## 局外循环

```text
关卡选择 -> 委托 -> 结算（星级/目标/协会使用）
   ↑                         ↓
   └── 委托解锁/协会解锁/人情 ←┘
                 ↓
            无尽悬赏
```

- 关内金币/声望/协会合作每局重置。
- 局外保存：委托解锁、星级、协会解锁、人情、无尽最高分；站位顺序/镜头/窗口存入独立的 `settings.json`，恢复/新档不覆盖。
- 失败无损；重试重置本局，不重置局外。
- 存档管理：主档 + 最近 8 个轮换备份；新存档前自动备份。

| 输入 | 行为 |
|---|---|
| 1-8 | 当前出生路线招募职业 |
| Alt+1-8 | 下一出生路线招募 |
| Q/E | 切换出生路线并跟随 |
| 左键/拖框 | 选单位；Shift 加选（锚点可在道路外） |
| 右键地面 | 移动选中单位 |
| Shift+右键 | 设置当前路线集结点 |
| H / R | 驻守 / 返回集结点 |
| 滚轮 / - / = | 摄像机缩放 0.5–1.5× |
| B | 协会面板 |
| F1 / F2 | 战地指南（←/→ 翻页）/ 首局步骤 |
| Hover 卡牌 | 查看定位/攻甲/被动/克制 |
| 右上“下一波” | 下一波路线/单位/目标 |
| 选中面板 | 按 协会/攻型/甲型/职业 分组；点击分组后移动/驻守/归线 |

| Space / Esc | 暂停菜单 / 打开暂停菜单 |

## 单局节奏

| 时间 | 内容 |
|---|---|
| 0:00-0:30 | 读委托；B 建交；出基础兵；设集结点 |
| 0:30-3:00 | 第 2-4 波；第一次声望晋级；协会关系 1 |
| 3:00-5:00 | 目标击杀；关系 2 职业；多路线/交汇压力峰值 |
| 5:00-7:00 | 最后一波；清残敌；结算星级 |

## 集结点、容量与战斗

- 新兵从基地生成，沿当前出生路线走到该路线集结点后驻守；默认在入口附近。
- 玩家用 `Shift+右键` 压集结点；Q/E 切换出生路线；Alt+1-8 在下一路线招募。
- 每条道路边按宽度生成横向碰撞槽位，双方共享；槽满单位在节点排队，按编队 rank/站位顺序进入。
- 框选多个单位移动时按出生路线分组编队：全队不超过最低速度，队首带路，后排按间距跟随/等待/反向，跨路线各自汇合。
- 单位有碰撞箱（`body_width/body_height`），用于槽位、绘制、选中；不做物理挤压。
- 单位接敌后战斗优先于移动；清敌后回到编队 slot/集结点；可沿道路反向移动。
- 友军受击会共享威胁：附近远程在射程内自动支援，近战优先反击攻击者。
- 到达目标点会吸附，不再来回抖动。
- 所有波次出完后，未手动驻守的己方单位会主动清理残敌，避免卡关。
