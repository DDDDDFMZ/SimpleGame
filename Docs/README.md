# SimpleGame 设计文档

> 项目代号：**SimpleGame**（正式名称待定）
> 类型：横版双线推兵策略 + 轻塔防关卡
> 引擎：Godot 4.x ｜ 平台：PC ｜ 画面：像素风
> 当前阶段：前期策划（无代码）

## 一句话

用金币和后勤建筑滚起军团，在两条战线上判断该守、该推、该换线。

## 状态图例

所有章节和任务必须带阶段标签：

| 标签 | 含义 |
|---|---|
| `首版` | 6 个月 Demo 必须完成，进入当前待办与工时预算 |
| `后期` | Demo 之后、正式版之前；写清扩展点，不排期 |
| `远期` | 联机、英雄阶段等愿景内容；只做架构预留，不实现 |

没有标签的内容视为文档错误。

## 阅读顺序

1. 先读 `00` 和 `01`，理解游戏是什么、玩家每局做什么。
2. 再读 `02` 和 `03`，这是数值与系统的唯一事实来源。
3. 开发前读 `06` 和 `07`，按 `08` 执行。
4. `09` 用于吵架时查旧账：已锁定决策不重复讨论。

## 维护规则

- 每次试玩后更新：`09` 的待验证假设、`02/03` 的数值、`08` 的工时。
- 新想法先写进 `09` 的 Parking Lot，标 `后期/远期`；不得直接塞进首版待办。
- 文档与实现冲突时，以可玩版本为准，回头改文档。
- 文件命名固定，新增文件需在 README 索引登记。
- 当前版本：v0.1（2026-10-28，初稿）。

## 术语表

| 术语 | 含义 |
|---|---|
| 路 / Lane | 一条水平战线；首版 2 条，单位不能主动换路 |
| 波次 / Wave | 一次敌军进攻批次，由固定波次表或预算生成器产生 |
| 推进线 / Advance Line | 每路新兵出生后前往并驻守的位置，默认在基地门口；早期文档称“集结点”，现统一用推进线 |
| 推线 | 单位沿路自动向敌方基地推进 |
| 软克制 | 攻型 x 甲型的伤害乘数，可被被动技能局部改写 |
| 人口 / Pop | 同时在场兵力上限，由基地与兵营提供 |
| 基地血量 / Lives | 防守关的失败条件；敌人抵达基地扣血 |
| 镜像敌军 | 敌方复用玩家 6 兵种，仅换色/换皮，不单独做美术 |
