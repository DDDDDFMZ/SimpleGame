# SimpleGame 设计文档（M7.3）

> 项目代号：SimpleGame ｜ 类型：俯视自动推兵 + 冒险者公会经营 ｜ 引擎：Godot 4.7 ｜ 平台：PC
> 当前状态：M7.3 已实现（路径容量无上限、路宽分排、友方相让/敌方不让、WASAPI 报错修复；叠加 M7.1/M7.2/M7 全部功能，全中文 UI）

## 一句话

小有名气的冒险者团长，用金币雇职业冒险者，靠声望与协会人情滚雪球，在灰港的多条道路上挡住赤旗团。
