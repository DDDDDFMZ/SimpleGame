# SimpleGame 设计文档（M4）

> 项目代号：SimpleGame ｜ 类型：横版双线自动推兵 + 冒险者公会经营 ｜ 引擎：Godot 4.7 ｜ 平台：PC
> 当前状态：M5 已实现（M4 + 卡牌/波次/目标信息、C1 引导、Field Guide、CSV 数值表、C3 重调）

## 一句话

小有名气的冒险者团长，用金币雇职业冒险者，靠声望与协会人情滚雪球，在两条路上挡住赤旗团。
