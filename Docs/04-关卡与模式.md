# 04 契约、关卡与模式（M4）

> 状态：`首版`：3 张契约 + 无尽 ｜ 关联：[03-经济](03-经济与建筑.md)、[10-剧情](10-世界观与剧情.md)
> TL;DR：M4 是 3 张线性契约 + 无尽。契约 1 只开铁誓会；通关 1 开绿荫；通关 2 开星环；通关 3 开无尽。每关 3-5 个目标敌人。

## 流程

```text
关卡选择 -> 契约 1（铁誓） -> 契约 2（铁誓+绿荫）
        -> 契约 3（三协会） -> 无尽
```

- 启动进入关卡选择；未解锁契约显示 LOCKED。
- 通关解锁下一契约；星级记录；协会解锁按契约进度。
- 失败无损，重试重置本局金币/声望/协会合作，但保留局外解锁/星级/人情。
- 星级：1★ 通关；2★ 基地≥12；3★ 基地≥18。
- 结算写入存档：星级（取最高）、下一契约、协会解锁、人情、无尽最高分。

## 无尽：无尽悬赏

- 通关契约 3 后解锁。
- 2 路，基地 20；使用局外已解锁协会/人情；关内金币/声望/协会合作照常重置。
- 波次预算：`B(w)=40+14w+1.2w²`；清空一波后 18-0.5w 秒（最低 8s）下一波。
- 每 3 波至少 1 个目标敌人；精英概率随波数提高；无胜利条件，基地归零结束。
- 分数：`wave×100 + kills×10 + 剩余基地×50`；最高分写入存档。
- 无尽不做局内三选一；后续可加。
