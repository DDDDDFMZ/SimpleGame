# 04 委托、关卡与模式（M7.2）

> 状态：`首版`：3 张委托 + 无尽 ｜ 关联：[03-经济](03-经济与建筑.md)、[10-剧情](10-世界观与剧情.md)、[12-地图](12-地图格式与编辑器.md)
> TL;DR：3 张线性委托 + 无尽；地图为单玩家/单敌方基地的节点图，多出生路线/交汇。委托 1 只开铁誓；通关 1 开绿荫；通关 2 开星环；通关 3 开无尽。每关 4-6 个目标敌人。

## 流程

```text
关卡选择 -> 委托 1（铁誓） -> 委托 2（铁誓+绿荫）
        -> 委托 3（三协会） -> 无尽
```

- 启动进入关卡选择；未解锁委托显示“尚未解锁”。
- 通关解锁下一委托；星级记录；协会解锁按委托进度。
- 失败无损，重试重置本局金币/声望/协会合作，但保留局外解锁/星级/人情/站位。
- 星级：1★ 通关；2★ 基地≥12；3★ 基地≥18。
- 结算写入存档 v4：星级（取最高）、下一委托、协会解锁、人情、无尽最高分；站位/镜头/窗口设置独立存 `user://settings.json`。

## 无尽：无尽悬赏

- 通关委托 3 后解锁。
- 默认节点图（2 条玩家路线）；基地 20；使用局外已解锁协会/人情；关内金币/声望/协会合作照常重置。
- 波次预算：`B(w)=40+14w+1.2w²`；清空一波后 18-0.5w 秒（最低 8s）下一波。
- 每 3 波至少 1 个目标敌人；精英概率随波数提高；无胜利条件，基地归零结束。
- 分数：`wave×100 + kills×10 + 剩余基地×50`；最高分写入存档。
- 无尽同样有容量排队/站位顺序。

- 路径 `user://save.json`；写入前回读校验；旧主档轮换到 `user://backups/`（保留 8 个）。
- 损坏主档隔离到 `user://corrupt/`，自动回退最近备份。
- 关卡选择 `S`：查看/恢复备份、手动备份、新存档（先自动备份当前）。
- 设置独立在 `user://settings.json`（v1）：默认镜头缩放、窗口缩放/全屏、站位顺序；旧 v2/v3 存档的 `settings` 首次启动迁移，之后恢复/新档不再读写设置。
- 损坏设置隔离到 `user://corrupt/settings_*.json` 并写回默认值，不进入存档备份列表。
- 不做战斗中途存档。
