## 文件

| 文件 | 内容 |
|---|---|
| `data/balance/units.csv` | 8 职业数值、协会/层级/角色/被动/治疗/站位顺序 |
| `data/balance/guilds.csv` | 协会中英文名、定位说明、解锁委托 |

| `data/levels/*.json` | 每关波次/简报/目标/地图引用 |
| `data/maps/*.json` | v2 节点图（nodes/edges/spawns）；调试编辑器 F3 / `--map-editor` |

旧 `data/units.json`、`data/guilds.json` 已不再加载；改它们不会生效。

## 编辑规则

- UTF-8 **无 BOM**；逗号分隔；小数用 `.`（不要 `,`）。
- 不要改表头/列名；不要插入空列；一行一个单位/协会层级。
- 布尔写 `true/false`。
- 改完运行验证：

```bash
"D:/Godot_v4.7/Godot_v4.7-stable_win64.exe" --headless --path . --script tools/validate_data.gd
```

- 游戏启动读取一次；改完需重启（热重载后续）。

## units.csv 列

`id,name_key,display_name,display_name_cn,guild,relation_tier,role,recruitable,cost,pop,hp,damage,attack_interval,range,speed,attack_type,armor_type,passive,projectile_speed,cooldown,heal_amount,heal_interval,heal_range,station_rank,sort_order,notes`

- `display_name_cn`：游戏内中文名。
- `guild`：`iron/verdant/arcane`；`relation_tier` 0-3。
- `role`：`vanguard/anti_armor/shock/ranged/flanker/siege/aoe/support`。
- `attack_type`：`melee/ranged/siege`；`armor_type`：`light/heavy`。
- `station_rank`：默认站位顺序（0=最前）；玩家可在暂停菜单覆盖。
- `heal_*` 只对 `heal` 被动生效。

## guilds.csv 列

`id,name,name_cn,short,short_cn,identity_cn,unlock_after,sort_order,notes`

- `identity_cn` 是 UI 展示的定位（前排/远程/法术）。
- `unlock_after` 是局外解锁所需委托数。

## guild_tiers.csv 列

`guild_id,tier,cost,cap,rank_gate,notes`

- `tier` 0-3；`cap` 加到兵力上限；`rank_gate` 所需声望 Rank。
- M7 三协会费用/上限相同；M8 计划差异化。

## 关卡/波次/地图

- `data/levels/*.json`：`map` 引用 v2 图；波次用 `route`（或旧 `lane` 索引）指定敌方出生路线。
- C3 起始金币 240；C1/C2 200。
- 地图宽度决定每边容量；容量小会在节点排队。改宽后跑自动试玩。
- 改波次后运行：

```bash
"D:/Godot_v4.7/Godot_v4.7-stable_win64.exe" --headless --path . --script tests/autoplay.gd
```

## 调参原则

1. 先改一个杠杆（数量/成本/HP/收入/路宽），不要同时改 5 个。
2. 自动试玩是下限；真人试玩是目标。
3. 信息层先于数值；容量/站位要能被看懂。
4. 每次调参记录：改了什么、为什么、自动结果、真人结果。
5. M7 不改协会/晋级数值；相关 backlog 在 [08](08-待办清单.md)。
