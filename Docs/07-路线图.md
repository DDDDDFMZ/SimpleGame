# 07 路线图与开发流程

> 状态：`首版` ｜ 关联：[08-待办清单](08-待办清单.md)、[09-风险与决策记录](09-风险与决策记录.md)
> TL;DR：单人业余、10-15 小时/周、6 个月。总计约 282 小时任务 + 58 小时缓冲 = 340 小时规划。先做可玩核心，再堆内容，最后换皮。

## 前提

| 项 | 假设 | 不成立时 |
|---|---|---|
| 人力 | 单人 | 加人先加美术，不加系统 |
| 时间 | 10-15 小时/周，约 26 周 | 按 10h/周 只有 260h，启动砍功能顺序 |
| 技能 | 会基础 Godot/GDScript；美术可占位 | 美术全用素材包，不改玩法范围 |
| 目标 | 6 个月 itch.io Demo | 延期不扩范围，只补 bug |

**规划工时：340 小时**（282h 任务 + 58h 缓冲）。每周按 13 小时中位数排。

## 开发流程

```text
预制作（现在） -> 原型（M1） -> 垂直切片（M2-M3）
	  -> 内容生产（M4-M5） -> 打磨与发布（M6）
```

### 每周节奏

| 时间 | 事项 | 产出 |
|---|---|---|
| 周一 30 分钟 | 选本周 3 个任务（来自 [08](08-待办清单.md)） | 本周目标 |
| 工作日 | 2-3 次开发，每次 2-4 小时 | 可运行提交 |
| 周五 30 分钟 | 构建 + 自玩 1 局 | bug 列表/手感记录 |
| 周日 30 分钟 | 更新文档/工时/风险 | 下周调整 |

### 每月节奏

- 月末必须有 **可玩构建**，不是“代码写完”。
- 对照本月退出标准；未达标则砍范围，不延期堆功能。
- 更新 [09](09-风险与决策记录.md) 的试玩记录与假设验证。

## 6 个月里程碑

### M1：模拟层跑通（50h）

**目标**：一个黑盒战场，能出兵、自动打、分胜负。

| 交付 | 验收 |
|---|---|
| Godot 工程、输入映射、目录结构 | 能启动 `battle.tscn` |
| 固定 20Hz 模拟层、2 路、单位移动/索敌/攻击/死亡 | 双方各 5 个单位自动打完 |
| 基地血量、胜负判定 | 一方基地归零弹结果 |
| 1 个兵种（剑盾）双方镜像、占位方块 | 能看出谁打谁 |
| 基础调试 UI（金币/血量/波次） | 数字随战斗变化 |

**明确不做**：经济、建筑、6 兵种、镜头/小地图、音效、美术。

**退出标准**：连续玩 3 局不崩；TTK 与移动速度“看起来不别扭”；模拟层有 3 个以上单元测试。

### M2：经济与 6 兵种（60h）

**目标**：一局完整的 5 分钟防守关。

| 交付 | 验收 |
|---|---|
| 金币/人口/击杀奖励 | 能造农场/兵营并看到收入变化 |
| 6 兵种 + 软克制 + 被动 | 每兵种都能出兵并生效 |
| 农场/兵营固定槽位、升级 | 4 槽位可建可升 |
| HUD、出兵栏、建筑面板 | 不用调试面板也能玩 |
| 第 1 关完整波次 | 4 波、教学提示、胜负结算 |
| 占位音效（可选） | 点击/命中不静音 |

**明确不做**：镜头切换/小地图、拖拽编队、存档、关卡选择。

**退出标准**：自己完整打通第 1 关 3 次；能感到“先农场还是先兵”的取舍；没有卡死/负金币。

### M3：操控与 3 关（60h）

**目标**：垂直切片，能拿给陌生人玩。

| 交付 | 验收 |
|---|---|
| 跟随镜头 + 切路 + 小地图 | 两条路都能看、能切 |
| 推进线、拖拽编队、H/R | 新兵按线驻守；选中部队可移动/返回 |
| 第 2、3 关 | 5-6 分钟/关，标志性敌人成立 |
| 音效占位 + 波次警告 | 关键反馈有声 |
| 3 人内部试玩 | 记录卡点与时间 |

**明确不做**：第 4/5 关、无尽、存档、像素美术。

**退出标准**：陌生人 3 分钟内学会出兵与切路；能说出“哪路快崩了”；无阻断性 bug。

### M4：内容完整（60h）

**目标**：Demo 内容全部可玩。

| 交付 | 验收 |
|---|---|
| 第 4、5 关 | 全 5 关可通，难度曲线成立 |
| 无尽模式 | 预算生成、计分、失败结算 |
| 存档/解锁/星级记录 | 退出重进进度不丢 |
| 关卡选择/结算/暂停/设置 | 完整流程闭环 |
| 首轮平衡 | 每关 1★ 可通过，3★ 需要思考 |

**明确不做**：像素美术替换、音乐、第二阵营、新目标类型。

**退出标准**：从启动到通关第 5 关无阻断；无尽能玩到第 10 波；存档往返正常。

### M5：表现与打磨（60h）

**目标**：看起来像一款游戏，而不是原型。

| 交付 | 验收 |
|---|---|
| 6 兵种像素动画 + 敌军换色 | 640x360 下可辨认 |
| 环境/建筑/UI 像素资源 | 不再是纯色块 |
| VFX、音乐、音效 | 战斗有打击感 |
| UI/UX 打磨、教学提示 | 新玩家不迷路 |
| 3-5 人外部试玩 | 记录留存/卡点/难度 |

**明确不做**：联机、英雄、新玩法、Steam 页面。

**退出标准**：截图可发 itch；外部玩家能独立完成第 1 关；无严重可读性问题。

### M6：发布准备（50h）

**目标**：itch.io Demo 上线。

| 交付 | 验收 |
|---|---|
| Bug 修复与性能 | 60 FPS，无崩溃 |
| 设置/存档/分辨率 | 1080p/720p 正常 |
| itch 页面、截图、预告 GIF | 能完整描述游戏 |
| 构建与上传 | 下载即玩，无需安装依赖 |
| 已知问题清单 | 发布说明诚实 |

**明确不做**：任何新系统、新关卡、新兵种。

**退出标准**：Demo 退出标准（下）全部满足；有 24 小时缓冲。

## Demo 退出标准

- 内容：5 关（最低 3 关：1、2、5）+ 无尽模式 + 6 兵种 + 农场/兵营。
- 流程：启动 -> 关卡选择 -> 战斗 -> 结算 -> 解锁 -> 重试/下一关，无阻断。
- 稳定：连续玩 30 分钟不崩；存档退出重进不丢。
- 性能：1080p 60 FPS；同屏 60 单位不明显掉帧。
- 可读性：新玩家 3 分钟内理解出兵、金币、双线；无需读外部说明。
- 表现：有像素美术、基础音效、至少 1 首战斗音乐。
- 发布：itch 页面 + Windows 构建 + 操作说明 + 已知问题。

## 砍功能顺序（范围失控时）

按顺序砍，不跳步：

1. **无尽模式延期**：保留入口占位，标“即将推出”。
2. **关卡 5 -> 3**：保留 1（教学）、2（重甲）、5（综合）；3/4 作为后续更新。
3. **小地图简化**：固定全览 + 路切换按钮，取消自由镜头/点击跳转。
4. **美术保持占位**：只做 UI 与兵种可读性，不做环境精修。
5. **音频只留核心 SFX**：音乐延期。

不砍：

- 自动战斗手感（移动/索敌/TTK）。
- 金币 + 农场/兵营核心。
- 第 1 关教学。
- 存档与失败重试。
- 双线换线（这是游戏的差异点）。

## 缓冲与延期

- 每月预留约 10 小时缓冲（已含在 340h 中）。
- 任何里程碑超时 > 20%，立即执行砍功能顺序，不压缩测试时间。
- 延期最多 1 个月；仍不扩范围，只修发布阻断问题。

## Open Questions

- 340h 规划是否符合真实可支配时间？第一个月后按实际速度修正。
- 第 4/5 关是否值得在 Demo 做？若 M3 试玩显示内容疲劳，直接砍到 3 关。
- 外部试玩从 M3 还是 M5 开始？建议 M3 至少 3 人，M5 再扩到 5 人。
- 是否参加 itch 的 game jam 逼出 Demo？可作为 M6 的外部截止线。
