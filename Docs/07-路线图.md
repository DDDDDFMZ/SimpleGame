## M6：两路数据化 + 调试编辑器 + 选中信息（估 45-70h）

1. 地图 JSON：world bounds、2 个 base、2 条直线 route、宽度 segments、spawn points；levels 引用 map。
2. 运行时仍两条直线路；不做交汇/多向；保留旧 `lane` 兼容。
3. 调试用游戏内地图编辑器：基地/路线/宽度/波次预览/校验/导出 JSON；`OS.is_debug_build()` 或 `--map-editor`。
4. 选中信息/分类（用户指定 M6）：数量/职业/阵营计数、合计 HP、分类 tab（阵营/攻型/甲型/职业）、分组移动。
5. 道路宽度（两路）可提前。
6. 不做：玩家导入、真图、多基地。

## M7：真图地图 + 玩家编辑器 + 装饰高度（估 80-150h）

- 玩家地图编辑器/导入导出；Godot EditorPlugin 可选。
